usage: specy-road worktree prune [-h] [--yes] [--repo-root DIR] NODE_ID

Remove work/.worktrees/<codename> for NODE_ID only when the worktree's HEAD and
feature/rm-<codename>, local, remote-tracking and on the remote wherever they exist, are merged
into the remote's actual integration tip (read with git ls-remote whatever the fetch refspec says,
its commits fetched by name; a remote that cannot be read refuses), and it has no uncommitted
changes, untracked non-ignored files, or stashes whose subject does not name another branch. Each
nested_repos repository in it must also hold no uncommitted changes, stashes, or commits that no
branch or remote-tracking ref of the main checkout's copy holds (a full clone's own branches and
remote-tracking refs included). Any other directory in it holding a .git (another repository's
linked worktree, checkout or submodule) or a bare repository, found by walking the filesystem,
refuses, as does a directory that walk cannot read, naming its repository, branch and the commits
its upstream lacks. Lists each ignored file removal deletes, including those inside ignored
directories; removes only with --yes.

positional arguments:
  NODE_ID

options:
  -h, --help       show this help message and exit
  --yes            Remove the worktree after the checks pass.
  --repo-root DIR  Project root (default: $SPECY_ROAD_REPO_ROOT, else the root recorded in
                   .specyrd/manifest.json, else the nearest enclosing roadmap/, else the git root,
                   else the current directory).
