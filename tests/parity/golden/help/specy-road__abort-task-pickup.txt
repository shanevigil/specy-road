usage: specy-road abort-task-pickup [-h] [--repo-root DIR] [--base BRANCH] [--remote NAME]
                                    [--force]

Abort a do-next-available-task pickup: remove registry row on the integration branch (commit +
push), delete the local feature/rm-* branch, and remove pickup files under work/.

options:
  -h, --help       show this help message and exit
  --repo-root DIR  Project root (default: $SPECY_ROAD_REPO_ROOT, else the root recorded in
                   .specyrd/manifest.json, else the nearest enclosing roadmap/, else the git root,
                   else the current directory).
  --base BRANCH    Integration branch (default: roadmap/git-workflow.yaml, else main).
  --remote NAME    Git remote (default: roadmap/git-workflow.yaml, else origin).
  --force          Allow abort when this branch has commits not on the remote integration branch
                   (deletes the local feature branch with git branch -D; may drop commits). Also
                   removes work/implementation-summary-<NODE_ID>.md if present.
