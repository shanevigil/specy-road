# Review lessons

Defect classes that escaped a review once. Every reviewer prompt (`specy-road prompt --role reviewer`) includes the entries below under **Project review lessons**, so each later reviewer checks the diff for them.

Add one with `specy-road lessons add --rule "<one-line rule>" [--example "<text>"] [--from <NODE_ID>]`; list them with `specy-road lessons list`. One entry per defect class: a top-level bullet with the rule, and optional `Example:` and `From:` sub-bullets.
