# Vision

specy-road is the coordination kit a small team installs so that its roadmap, contracts and planning narrative live beside the code and drive the work: coding agents pick real leaves from a validated graph, implement inside declared touch zones, hand off to independent reviewers, and finish through a deterministic gate, while the humans decide what is worth building and whether it mattered. The toolkit itself is run this way: its own roadmap (this tree) is the first adopter of every feature it ships, and each release candidate is judged by what adopters report back.
