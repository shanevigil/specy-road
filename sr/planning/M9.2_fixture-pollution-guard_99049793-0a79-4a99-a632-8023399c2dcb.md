## Intent

Regression 6: a manual CLI run left `.specyrd/cache` inside `tests/fixtures/specy_road_dogfood`, and two tests failed later with no hint why. Make pytest refuse to run on a polluted fixture tree and fail a run that pollutes it. Design: `docs/design-notes/regression-prevention.md`.

## Approach

Put the check in `tests/fixture_guard.py` (status of `tests/fixtures` via `git status --porcelain --ignored`) and wire it from `tests/conftest.py` with `pytest_sessionstart` / `pytest_sessionfinish`; `pytest.exit(..., returncode=...)` at start. The test runs pytest in a subprocess on a temporary git repo that copies the guard, so it never touches the real fixture. One paragraph in `docs/contributor-guide.md`. Verify with `pytest tests/test_fixture_guard.py` and a full `pytest` on a clean fixture tree.
