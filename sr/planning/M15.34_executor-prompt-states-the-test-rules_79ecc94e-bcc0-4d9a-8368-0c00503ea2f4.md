## Intent

The reviewer prompt carries an excess checklist (`role_prompt_rca._EXCESS_CHECKLIST`) that blocks tests pinning internals and overlapping tests. The executor prompt (`executor_preamble`) never states those rules. They live in the project's `.specyrd/AGENTS.md` / agents-rules, which an adopter's clones did not track. Executors then wrote tests that reviewers blocked by rule.

## Approach

- In `role_prompt_rca.py`, define a `TEST_RULES` tuple with three sentences: no test imports or patches a `_`-prefixed name or asserts mock call counts, call order, or log text no caller relies on; extend or parametrize an existing test before adding one, and add a test only for a distinct regression; never weaken, rewrite, or delete a failing behavioural test.
- `executor_preamble` adds a short `Tests:` block from that tuple after step 3.
- The reviewer checklist's two test bullets quote the same strings, so the prompts cannot drift.
- One test builds both prompts (existing prompt-test helpers) and asserts each sentence in both.

## Tasks / checklist

- [ ] A1: shared tuple; executor block; reviewer bullets reuse it.
- [ ] A2: test over both prompts, which also covers the rework prompt.
- [ ] A3: Out of scope: reading project rule files at prompt time, project-specific test rules.
