## Intent

The docs say to export `SPECY_ROAD_REPO_ROOT`; a worker running `specy-road ready` in a linked worktree then resolved the main checkout and was refused. In another repo pickup --worktree created worktrees without the gitignored venv and node_modules; the coordinator symlinked them, the directory-only ignore patterns (`node_modules/`) did not match the symlinks, and `worker delegate` refused the "dirty" tree.

## Approach

- `runtime_paths.py`: when the variable names a checkout and cwd is inside a linked worktree of the same repository (same common git dir), use the enclosing worktree.
- `worker_ops_launch.py`: set the variable to the worktree in the worker's env.
- `worktree_env.py` (108): a `link:` list in env_setup; create symlinks and add names to `.git/info/exclude` of the worktree (per-worktree exclude lives in the common dir; check git's behaviour and document it).
- Docs: new `docs/orchestration-worktrees.md`.
