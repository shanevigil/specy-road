## Intent

Final sandbox rehearsal, 2026-11-06 (sr/work/sandbox-feedback/2026-11-06-rc4-final-2c45d7e8.md, finding F3). `specy-road digest --check` on a repository with no roadmap manifest prints an 11-frame traceback ending in `FileNotFoundError: no roadmap manifest: expected <root>/roadmap/manifest.json`, exit 1. `export --check` and `validate` print the same sentence as a clean error. Reproduced on the checkout (an empty `git init` directory, `--repo-root`): export --check prints one line, exit 1; digest --check prints the traceback.

`cmd_digest` calls `render_digest(root)` before anything else, and that call raises from `roadmap_chunk_utils` (`discover_manifest_path`). `export_roadmap_md.main` catches it: it calls `discover_manifest_path(root)` first and prints `str(e)` on stderr, exit 1.

## Approach

- `digest_cli.cmd_digest`: call `discover_manifest_path(root)` first, the way `export_roadmap_md.main` does; on `FileNotFoundError` print its message on stderr and return 1. This covers plain `digest`, `--check` and `-o -` alike.
- No change to `render_digest` or to the message text.
- Smallest change: one guard in `cmd_digest`; M21.37 edits the same file (output writes through `safe_write`), so this leaf follows it.
