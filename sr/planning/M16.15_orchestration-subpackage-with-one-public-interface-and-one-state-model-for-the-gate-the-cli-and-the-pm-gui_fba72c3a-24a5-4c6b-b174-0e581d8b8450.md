## Intent

Workers and orchestration are canonical specy-road (maintainer, D1). They are 12k lines across 65 modules with no boundary, and the 0.3.2 PM GUI will show orchestration and worktree state. Defining the interface and state model first lets M16.16-M16.19 move code behind it one sub-area at a time.

## Approach

- Interface first, then readers switch to it, then (in later leaves) modules move.
- The snapshot is read-only; writes stay where they are until their sub-area moves.
- Field names are part of the interface; version the snapshot with a `schema` integer.
- Depends on: M16.1, M16.5, M16.6. Expected net line delta is the last acceptance line; report `scripts/lean_metrics.py --check` deltas in READY once M16.2 has landed.
- Behaviour-preserving: the parity harness (M16.0) and the review-gate decision table (M16.1) stay green; no function rises above its merge-base complexity.
