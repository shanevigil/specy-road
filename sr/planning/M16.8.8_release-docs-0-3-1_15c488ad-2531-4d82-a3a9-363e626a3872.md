## Intent

The last content pass before the 0.3.1 tag: after the end-to-end pass (M16.8.4) and its fix leaves land, and after the alias window closes (M16.8.3), the docs adopters read first describe what actually ships. M16.6.1 restructures the docs by topic mid-milestone; this leaf is the final consistency sweep and the release summary, not a second restructure.

Out of scope: writing the `## [0.3.1]` heading, bumping `project.version` and tagging. Those are human-owned and happen at promotion. No product code changes; a doc that reveals a behaviour bug becomes a fix leaf.
