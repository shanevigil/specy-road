## Intent

The first real sandboxed fix round (M22.16) could not read its blocking review. M22.44 mounts an empty outbox at `work/reviews/<node>`, which hides the records there, so the worker had only the text quoted in the message.

## Approach

In `prepare`, copy the regular files from the reviews directory into the outbox before the turn. `_deliver_ready` already moves only READY files back.

## Tasks / checklist

- [ ] Seed the outbox
- [ ] Tests, CHANGELOG

## Tier

behavioural: a fix round can pass while working from less evidence.

## Done but wrong

- The worker sees the record but could change what reviewers rely on. Check: a changed REVIEW copy does not reach the reviews directory.

## If this fails

If copying is too slow for large histories, copy only top-level files and leave `history/` out; the coordinator decides.
