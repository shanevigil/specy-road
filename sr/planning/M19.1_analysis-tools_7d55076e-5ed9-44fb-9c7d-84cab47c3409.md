## Intent

specy-road ships ruff-based quality checks (M16.8) but a project may already run its own analysis tools. Let the project choose: the built-in set, or its own tools declared through `checks:`. When tools are already installed, an agent can propose the configuration that matches what specy-road ships, without installing anything.

## Approach

- Build on `checks:` (M16.14) and zone-scoped, merge-blocking entries (M16.52); declared tools run through that machinery, not through tool-specific code paths.
- Detection reads what is already installed (the project's environment and PATH) from a small table of known tools; it never installs, upgrades or writes config on its own.
- Prefer a shipped agent prompt over a new command if the command budget is tight; the acceptance allows either.
- Depends on: M16.52, M16.14 (and the phase's dependency on the 0.3.1 tag gate M16.66).
