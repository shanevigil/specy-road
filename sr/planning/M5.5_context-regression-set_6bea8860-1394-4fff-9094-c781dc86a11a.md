## Intent

A harness or model upgrade that breaks the managed guidance is caught before adopters hit it.

## Approach

The harness runs the cases, never the CLI. Pass/fail comes from recorded files (review records, commits), not model judgement. Cases come from the review-round test modules and the sandbox evidence.

## Tasks / checklist

- [ ] Select cases
- [ ] Write the file and runbook step
- [ ] Schema test
