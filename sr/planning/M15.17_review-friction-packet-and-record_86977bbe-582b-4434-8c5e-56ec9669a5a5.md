## Intent

Small review frictions that cost rounds: `review delegate` stops with "no review packet … run review-packet first"; the packet warns about gitignored build output and globs that match nothing; its "new suppressions" line numbers did not match the commit; `review record` refused approves over the "not a defect because" rule without showing the offending line (hit by two adopters and this toolkit); and `review list` shows a failed RUN record next to a REVIEW later filed at the same commit, which reads as a contradiction.

## Approach

- New `specy_road/review_delegate_packet.py`: build or refresh the packet for the target commit (`build_packet`), print path and size; `review_delegate.py` (395 after M8.3) calls it once.
- `review_packet_uncommitted_refs.py`: `git check-ignore` filter and a count line.
- `integrity.py` (395): fix the suppression line mapping to the commit's file; keep growth zero or move the helper out.
- `review_record_rules.py`: return offending lines with numbers; printed by the refusal in `review_record_write.py` / `review_cli.py`.
- New `specy_road/review_run_status.py`: decide `superseded` for RUN records; `review_cli.py` (387) and handoff status call it.
