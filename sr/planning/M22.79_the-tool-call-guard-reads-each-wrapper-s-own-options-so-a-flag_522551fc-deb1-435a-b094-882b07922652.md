## Intent

The fifth gap in the tool-call guard, found 2026-11-19 by M16.7.7's guard property. The guard keeps one list of wrapper flags that take a value and shares it across every wrapper, so `sudo -n git stash` reads `git` as the value of `-n` and the command as `stash`; `command -p`, `time -p`, `doas -n`, `xargs -r`, `xargs -t` and `ionice -t` slip past the same way. This leaf gives each wrapper its own option table, as M22.77 did for env, and an option a wrapper does not know fails closed. Operator: "M22.79 ok" (RC blocker).

## Approach

- One small option table per wrapper (short letter, long name, whether it takes a value), parsed with the getopt rules M22.77 uses for env; reuse that parser rather than adding a second one.
- Extend the M22.77/M22.78 enumerated test with every table option per wrapper.
- No rule-table rewrite; that is M23.8.
- Depends on: M22.78. M16.7.7 and M16.8.4 depend on this leaf; M16.7.7 reruns unchanged after it lands.

## Tier

trust: it changes the guard that refuses destructive commands.
