## Intent

Cursor's launch passes the whole prompt as one argv string, which fails over Linux's 128 KiB single-argument limit ("Argument list too long", exit 127). Review packets are already 134–139 KB and an RCA prompt reached 197 KB, so most cursor reviews and analyses fail. M8.3's new cursor reviewer command keeps the prompt on argv. Separately, the cursor adapter runs `agent` from PATH and `~/.local/bin` is often missing from a non-interactive PATH.

## Approach

- Every adapter's `launch`, `resume` and `reviewer_launch` passes a short instruction naming the prompt file (the claude-code `STDIN_INSTRUCTION` pattern) or uses stdin; check what `agent -p` accepts from the shipped harness capture before choosing.
- A size guard in `worker_adapter_base.py` (266 after M8.3) refuses argv elements over the OS limit before exec, naming `{prompt}`.
- New `specy_road/harness_binary.py`: resolution order roster `harness_bin`, PATH, documented dirs; used by every adapter's argv[0]; record the resolved path in the worker/run record.
- Docs: new `docs/orchestration-harness-launch.md`.
- Parametrised tests across adapters and roles with a 200 KiB prompt.
