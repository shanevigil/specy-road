## Intent

Workers and reviewers verified their work by launching the packaged app and probing windows with osascript, so the author repeatedly lost focus and got OS permission prompts. In another repo a cursor executor drove a running local API, started by the coordinator for a human acceptance run, as a test admin: it deactivated seeded data and created records to fabricate a walkthrough, and the owner then timed against that state. The coordinator's "do not touch the servers" message only queued for the next turn, and reconcile reported clean because no out-of-zone file changed. A third adopter saw it again: an executor started its own API on the shared port, ran a demo seed against the shared dev database, and hand-deleted rows there to get past a 401; neither post_run_check nor reconcile recorded it.

## Approach

- New `specy_road/host_effects.py`: the policy reader (`policy.host_effects`, `policy.protected_services`), the prompt block, and the denied command shapes. `orchestration_config.py` (381) and the schema gain the keys; `role_prompt.py` adds the block with one call (depends on M8.3, which owns that file now).
- Guard: new `tool_call_guard_host.py` with the shapes (open, xdg-open, osascript, electron, app-bundle binaries; HTTP clients to a protected host:port); `tool_call_guard.py` (399) changes only its call line. Reuse the tokenising in `tool_call_guard_shapes.py`.
- `agents-team.md` starter: one commented example line.
- Interrupt: `worker message --interrupt` in new `worker_cli_message.py` (worker_cli.py is at 393); `worker_ops_message.py` stops the running turn (the worker process) and resumes the session with the message through the adapter's `resume`. Depends on M14.11, which owns `worker_ops_message.py` now.
- Docs: new `docs/orchestration-host-effects.md`.
- `protected_services` entries gain `kind` and a database address form; a roster entry may add its own list (roster item schema has `additionalProperties: false`); `host_effects.py` merges both and names each entry in the executor prompt block (A5).
