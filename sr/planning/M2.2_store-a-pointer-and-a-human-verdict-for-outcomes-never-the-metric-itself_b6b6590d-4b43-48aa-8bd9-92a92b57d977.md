## Intent

A node can carry the hypothesis it was built on and the human's verdict on what happened, without the CLI reading any metric.

## Approach

Schema first, then the edit-node whitelist (dotted keys for the sub-object), then promote and brief. No analytics integration (constitution: the CLI calls no model or API).

## Tasks / checklist

- [ ] Schema
- [ ] edit-node dotted keys
- [ ] promote carry-over
- [ ] brief line
- [ ] Docs
- [ ] Tests
