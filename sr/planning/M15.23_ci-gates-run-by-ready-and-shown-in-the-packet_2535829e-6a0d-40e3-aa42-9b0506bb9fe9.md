## Intent

An adopter's leaf passed six reviews over three rounds while the project's merge-blocking lint job reported 22 errors, all in files the leaf created. The executor chose its own READY verifiers and reviewers re-ran those or subsets; only a seventh review ran the exact CI command and blocked (its auto-fix would also have deleted a needed re-export). This toolkit hit the same gap twice in one night: ruff C901 failures surfaced only at the pre-land gate after both approvals, and the coordinator added a ruff precheck to its dispatcher as a stopgap. In that adopter's run the one reviewer that ran the CI command caught the regression that six others missed. `verify_cmd` names one test command; nothing names the merge-blocking set.

## Approach

- New `specy_road/ci_gates.py`: read `ci_gates` from `roadmap/git-workflow.yaml` through `load_git_workflow_config` (as `verify_cmd_config.py` does; `git_workflow_config.py` is at 396 lines), refuse duplicate names, and select the gates that apply to a list of changed paths with `finish_implementation_check.in_zones`.
- Schema: add `ci_gates` to `git-workflow.schema.json` (top-level `additionalProperties: false`); item object with its own `additionalProperties: false`.
- `ready`: after the executor's `--run` commands, run the applicable gates from the project root with the run helper in `ready_run_checks.py` (M15.24 moves `run_check` there and adds the failure-tail warning, which the gates then get for free). Rows carry `gate: <name>`; skipped gates go in the READY body. `review_gate_ready.py` is 252 lines, so keep the loop small or put it in `ci_gates.py`.
- Packet: new `bundled_scripts/review_packet_ci_gates.py` renders the section from the newest READY (`review_files.latest_ready`) and `same_commit`; `review_packet.py` (392) adds one call line in `build_packet`.
- `verify_cmd_lines` gains the gate sentence, so the executor brief and the reviewer prompt both carry it without touching `role_prompt.py` (owned by M8.3).
- Template `specy_road/templates/project/roadmap/git-workflow.yaml`: commented example; new `docs/git-workflow-ci-gates.md` (`docs/git-workflow.md` is at 384 lines).
- Overlap: M15.22 (claimed) also edits `git-workflow.schema.json`; merge the schema change on top of it.
