## Intent

The PM can finish triage without scripts and without a partial write.

## Approach

The triage path is `_triage` in brainstorm_cli; validate all ids first (by_id raises), then apply. `realize` sets promoted_node_key after checking the node exists in the merged graph. Summary counts come from the session; no new file.

## Tasks / checklist

- [ ] all-or-nothing triage
- [ ] realize
- [ ] append-why + help
- [ ] list --summary
- [ ] reason consistency
- [ ] Tests
