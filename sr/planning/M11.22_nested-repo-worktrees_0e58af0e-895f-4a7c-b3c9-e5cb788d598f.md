## Intent

Found in rc1/rc2 field use (2026-11-02). A project whose code lives in several separately versioned repositories under the root could not use worker delegate: the linked worktree contained none of them, so the executor had nothing to edit. The coordinator had to build worktrees by hand.

## Approach

Mixed: the maintainer should confirm the configuration shape before implementation; start with delegate and reconcile, then finish. Verify with the touched test files and file-limits.

Maintainer (2026-11-03): agentic; the nested_repos shape is approved. Repos outside the leaf touch zones get detached worktrees (read-only in practice). finish merges and pushes each nested repo branch before the main repo, so a nested failure stops the landing before the main repo moves. If a file you need is outside the touch zones, add it on your branch with specy-road edit-node M11.22 --add touch_zones=<path>, commit, and say why in the summary instead of stopping.
