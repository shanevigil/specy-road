## Intent

`review accept-policy` works one leaf at a time, so a single review policy change costs the maintainer one prompt per open claim. The check itself stays deterministic and needs no human while the fingerprint matches. This only makes the rare real change cheap to accept. Maintainer decision 2026-11-07.

## Approach

Add `--all-open`. Group open claims by the change they would accept, print each group once, ask for one typed confirmation, then write the same per-leaf acceptance file as today. Do not widen what an acceptance means: no standing or wildcard acceptance, and no path that works without a terminal.

## Tasks / checklist

- [ ] Add --all-open to review accept-policy
- [ ] Group changes and print each set once with its leaves
- [ ] One typed confirmation writes one POLICY-ACCEPTED.yaml per leaf
- [ ] Tests for the cases in the acceptance
- [ ] Docs and CHANGELOG
