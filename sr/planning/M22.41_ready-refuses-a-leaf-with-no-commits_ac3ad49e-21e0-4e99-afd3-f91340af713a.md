## Intent

A field run showed a worker that could not commit still reach review. `ready` wrote READY with `commit` equal to `base` and no changed paths, its `--run` checks passed against uncommitted files, and `handoff status` showed `ok` and offered review. Confirmed in `cmd_ready`: nothing refuses an empty leaf.

## Approach

Add one refusal in `cmd_ready`, before the `--run` commands, so a bad state costs no test run: HEAD equal to the merge base, or uncommitted changes inside the touch zones. Name the paths. Keep `blocked_on` working. Make the READY check that `handoff status` uses report an old empty READY as not ready.

- [ ] Stop showing ok for an empty READY
