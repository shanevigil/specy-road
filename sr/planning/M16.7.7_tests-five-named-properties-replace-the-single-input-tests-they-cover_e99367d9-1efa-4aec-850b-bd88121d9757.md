## Tier

behavioural: properties replace single-input tests, and a property whose generator rarely produces the hard cases passes while checking less than the tests it replaced.

## Done but wrong

- A property misses the cases the removed tests checked. Check: each removed single-input test's input is an explicit example on its property.
- A property does not fail when the behaviour breaks. Check: for each of the five, a scratch break of the subject (for example, outdent that appends at the end of the parent's siblings) makes the property fail.

## If this fails

The assumption most likely to break is that all five invariants hold in production code today. If a property finds a counterexample, the leaf cannot fix it (its zones hold no package code) and must not narrow the property to pass. Record the counterexample and stop. The maintainer decides between a separate fix leaf first and a narrower stated invariant.

## Accepted limits

- The registry round-trip covers the data; comments and key order in hand-edited YAML are not covered.
