## Intent

No-behaviour-change hygiene that the rest of the chain builds on. Dead code goes; shared clock, atomic-write, git and registry helpers arrive; one roadmap index answers graph queries; library modules leave `bundled_scripts`; a shrink-only layering gate is set and the two import cycles are broken; commands run in-process with `build_parser()`, lazy imports and one `SpecyError` base.

## Approach

Leaves run in id order, which is chain order: every leaf's prerequisites have a smaller id, and no edge points to a later group. There are no group-level dependencies; the leaf edges give the order.

Why together: This is the slimming recommendation's "mechanical clean-up" pass (RECOMMENDATION.md section 3.3 calls it pass 1; its pass labels are not these group ids), and it is the first contiguous segment of the code chain: helpers, then the index, then layering, then the in-process CLI. Later leaves resolve moved module paths through M16.2.5's committed move list.
