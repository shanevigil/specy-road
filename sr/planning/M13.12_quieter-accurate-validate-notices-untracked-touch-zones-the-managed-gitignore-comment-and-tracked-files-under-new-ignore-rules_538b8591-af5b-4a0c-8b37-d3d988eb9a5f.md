## Intent

Make three validate/upgrade notices short and true. The "touch zones that match no tracked file" notice was one ~3.5 KB line listing 85 nodes in an adopter repo, mostly Not Started leaves that will create the file; the coordinator hits it on every pickup too. The managed `.gitignore` comment says `.specyrd/manifest.json` stays tracked even in a repo that has no manifest. And for tracked files a new ignore rule matches, M13.7 lists them but does not say what to do.

## Approach

- **Touch zones.** In `warn_untracked_zones()` (`specy_road/bundled_scripts/touch_zone_tracked.py`), sort entries: claimed or In Progress nodes first, then other non-Not-Started, then Not Started; list at most 10; then "and N more (by status: …); `specy-road validate --all` lists every one". Not Started unclaimed leaves are only counted. Add `show_all: bool = False`; in `specy_road/bundled_scripts/validate_roadmap_checks.py` (399 lines) change only the call line to pass `show_all=show_all`, which `run_validation` already receives. Claims come from the registry `run_validation` already loads; pass them in rather than reading again.
- **.gitignore comment.** `_GITIGNORE_NOTE` in `specy_road/agent_ignores.py` and line 35 of `specy_road/templates/project/.gitignore`: reword so it is true with or without a manifest (e.g. "`.specyrd/manifest.json`, when present, stays tracked"). Prefer rewording over a conditional block, which would make the managed block differ per repo.
- **Tracked matches.** Extend M13.7's notice in `agent_ignores.py`: for tracked matches, print `git rm --cached <paths>` and one line: keep tracking if the file is meant to be shared (the rule only hides new files), untrack if it is session scratch. Never run it.
- **Verify.** Tests: 85 synthetic nodes → bounded output, `--all` → full; repo with no stub pack → comment true; tracked match → command printed.

## Tasks / checklist

- [ ] A1 — Untracked-zone notice capped at 10, priority order, counts by status; `--all` lists all; call-line-only change in `validate_roadmap_checks.py`.
- [ ] A2 — `.gitignore` comment and init template true with or without a manifest.
- [ ] A3 — Tracked matches get the `git rm --cached` command and keep/untrack guidance.
- Out of scope: untracking automatically; which ignore rules ship; the touch-zone prefix warning.
