## Intent

The shipped Codex guidance contradicts how specy-road runs Codex. harness-facts.yaml classifies `multi_agent` as avoid (triage F15), and the shipped Codex profiles, executor and reviewer templates and the model-profiles README pass `--disable multi_agent`, while the specy-road worker adapter and reviewer launches leave it on. The maintainer decided on 2026-11-19 ("Let codes run in multi agent") that Codex runs with multi_agent on, so the shipped facts and templates follow the code.

## Approach

- Change the `multi_agent` classification in harness-facts.yaml to use, noting the operator decision that supersedes F15's avoid.
- Remove `--disable multi_agent` from every shipped Codex template and profile cli line, then `specy-road upgrade --only profiles --render` and `--check`.
- The worker adapter, launch argv and reviewer wrappers stay unchanged; they already leave multi_agent on.
- Depends on: M22.73 (same files).
