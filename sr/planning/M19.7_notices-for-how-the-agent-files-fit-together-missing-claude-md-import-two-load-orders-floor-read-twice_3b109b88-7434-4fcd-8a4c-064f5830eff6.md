## Intent

Point out when the set of agent files does not fit together, so a project knows what each harness actually reads. Three cases from batch C: `CLAUDE.md` exists but does not import `@AGENTS.md`, so Claude Code never reads the project's rules there (validate's context line just leaves AGENTS.md out); the project's AGENTS.md defines its own load order while `.specyrd/AGENTS.md` defines another (roadmap-context.md first), and they disagree; and with `@AGENTS.md` imported, Claude Code reads the floor bullets twice, once in the full root block and once in `.specyrd/AGENTS.md`. The fix for the last is M13.3's `agents_block: minimal`, not dropping the `.specyrd` import, which would lose the full rules.

## Approach

- Add three checks to `specy_road/agent_text_report.py` (M13.8 creates it and its validate hook, so no further edit to `validate_roadmap.py`):
  - **Missing import.** `CLAUDE.md` exists; root `AGENTS.md` has non-blank text outside its managed block (`managed_block._split`); no line of CLAUDE.md is `@AGENTS.md` (with project prefix). Notice: "Claude Code skips AGENTS.md while CLAUDE.md exists; add `@AGENTS.md` outside the markers in CLAUDE.md".
  - **Load order.** In the project's AGENTS.md text outside the block, find a heading containing "load order" followed by a numbered list; compare its backticked paths with `load_order_paths()` (`specy_road/agents_md_block.py`, read only) over `.specyrd/AGENTS.md`; name what it omits, roadmap-context.md first.
  - **Floor twice.** CLAUDE.md imports both `@AGENTS.md` and `@.specyrd/AGENTS.md`, and the root block is the full one (not M13.3's minimal). Give the duplicated bytes (the floor bullets in the block) and name `agents_block: minimal` in `.specyrd/manifest.json`.
- **Template sentence.** In `specy_road/templates/specyrd/agents-rules.md`, under "### Load order", add one sentence: this order is a default a project may replace in its own files; keep `roadmap-context.md` first. Check the size tests that pin `.specyrd/` files (`tests/test_enforced_rules_pointers.py` and similar) and adjust only the budget for that file if one pins it.
- **Verify.** Fixture tests per notice, plus negatives (import present; AGENTS.md is only the block; minimal block). No file is written.
