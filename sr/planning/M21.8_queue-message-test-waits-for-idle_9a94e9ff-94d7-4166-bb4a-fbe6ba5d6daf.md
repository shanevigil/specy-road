### 20 consecutive passes under load (2026-11-05, re-run fix round 2)

From git root, four busy Python processes plus `pytest -n 4` on the target test. Background loaders must be killed before `wait`; otherwise `wait` never returns.

```bash
LOAD_PIDS=()
for _ in 1 2 3 4; do python -c 'while True: pass' & LOAD_PIDS+=($!); done
FAIL=0
for i in $(seq 1 20); do
  pytest tests/test_worker_queue_message.py::test_message_while_running_queues_and_delivers -q -p no:cacheprovider -n 4 || { FAIL=1; break; }
done
for pid in "${LOAD_PIDS[@]}"; do kill "$pid" 2>/dev/null; done
wait 2>/dev/null || true
exit $FAIL
```
