## Intent

A research register tracks deep-research topics with a refresh cadence. Done when:
- init project scaffolds research/README.md; a register entry research/<topic>.md records purpose, the tracked prompt file, cadence, last run date and the roadmap nodes its findings fed
- validate warns when a register entry is past its cadence or names a prompt file that does not exist
- Prompt files live under research/ (tracked), not work/
- docs/roadmap-authoring.md describes the register and the fold-findings loop (research -> brainstorm -> promote)

## Approach

Ship the register as a project template (`specy_road/templates/project/research/README.md`), which `init project` already copies, so no init code changes. Register entries are Markdown with YAML front matter (`purpose`, `prompt`, `cadence_days`, `last_run`, `fed`). `validate` gains a non-fatal `warn_research_register` pass in `validate_roadmap.py` that warns on an overdue or never-run entry, a missing prompt file, a prompt outside `research/`, or unreadable cadence or date fields; a project with no `research/` directory gets no warnings. Document the register and the research, brainstorm, promote loop in `docs/roadmap-authoring.md` within its line cap. The toolkit's own register belongs to M7.2. Verify with `tests/test_research_register.py`, the init-project scaffold test and `specy-road file-limits`.
