## Intent

Give the root-cause step a launcher, and an honest outcome when it cannot run. Escalation tells the coordinator to run `prompt --role rca --model <a reviewer that has not reviewed it>`, but `review delegate` does not cover that role, so the launch is hand-built. In the reported run it exited after 4 seconds because the only unused reviewer had hit its usage limit; the only evidence was an `ActionRequiredError` line in a log, nothing recorded the skip, and `handoff status` kept saying "next, a root-cause analysis" until the gate passed.

## Approach

- **Launcher.** New `specy_road/rca_delegate.py`. Reuse `review_delegate`'s run loop (harness adapter launch, retries with doubling backoff, RUN record via `reviewer_run_failure.save_run`/`close_run`) with the prompt from `role_prompt_rca.py` (what `prompt --role rca` builds) and the run file `RUN-rca-<model>.json/.log`. Success is a valid `RCA-*.md` for the escalation (the loader `loop_state()` uses). Register `review rca` from `review_delegate.add_parser()` (which `review_cli` already calls), so `review_cli.py` needs no parser code. Refuse a model in `rca_parties()` and list eligible ones. If M12.1 left `review_delegate.py`'s run loop as one function, extract the shared part rather than copying it.
- **No analyst.** If no rostered model is available and outside the parties, `review rca` and handoff status print the ways forward: an off-roster model (`--harness`), a human analysis recorded as an RCA with `escalate_human`, or M12.1's `fix_round_budget` / `review defer` path. Read M12.1's merged next-step text (`review_deferral.py`, `review_cli._render`) and extend it rather than adding a second "next" line. If `review_cli.py` has no room, move the escalation/next-step rendering into new `specy_road/review_status_render.py`.
- **Skipped runs.** A failed analyst run is recorded `state: skipped` with the reason; status shows "RCA skipped: <reason>" with the ways forward.
- **Usage limits.** In `specy_road/reviewer_run_failure.py`, add a usage-limit class separate from `CAPACITY` (Cursor `ActionRequiredError`, "usage limit reached", "out of credits", using `claude_code_limits.py` patterns where they fit). Such a failure is not retried; new `specy_road/availability_overlay.py` writes `available: false` (and `paused_until` when the output gives a reset time) for that roster id into `roadmap/orchestration.local.yaml`, the gitignored overlay `orchestration_config.load_availability_overlay()` already reads. Applies to reviewer runs too.
- **Docs.** `docs/design-notes/review-loop-rca.md`: launching the analyst and the no-analyst outcome.
- **Verify.** Tests with a fake harness: successful RCA run → RUN record and status clears; party model refused; usage-limit output → skipped, overlay entry written, plan excludes the model; no eligible model → the ways forward.
