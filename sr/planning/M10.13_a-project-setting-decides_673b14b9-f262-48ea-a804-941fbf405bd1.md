## Intent

Worker records and event logs are gitignored today by design and stay that way by default: a project config key (for example track_worker_logs: off, events, full; default off) lets a team opt in to keeping the event log, or the raw harness output too, in the repository so a leaf's run history travels with the code and the log explorer can read it from any clone. Off by default because the logs get very long.
