This leaf adds **one shared rule** and moves the setup and upgrade writers onto it. M21.38 (review writers) and M21.39 (publish, finish, pickup) build on it in parallel.

The rule (`specy_road/safe_write.py`): before any mkdir, write or delete, walk with `lstat` from the owned root (resolved once; nothing above it is inspected) to the destination. Every ancestor below the root must be a real directory. Refused, with `SafeWriteError(OSError)`:

- a symlink at any ancestor below the root, whether dangling, pointing inside the repo or pointing out;
- a non-directory where a directory belongs;
- a lexical `..` that leaves the root.

What the final component may be depends on the operation:

| Operation | Final component allowed |
|---|---|
| `write`, `copy` | absent or a regular file (a symlink of any kind, a FIFO, a directory: refused) |
| `mkdirs` | absent or a real directory (an existing real directory is fine) |
| `remove` | a regular file or a symlink entry; a symlink is unlinked as an entry, never followed |
| empty-directory prune | a real directory by `lstat`; a symlinked directory is never `rmdir`ed or listed |
| `open_lock` | absent or a regular file |

Message shape: the same sentence as finish's `irregular_destination`, `"<path> is <kind>, not <expected>"`, with ` (to <readlink>)` after `a symlink`, so `tests/test_finish_config_preflight.py`'s `roadmap.md is a symlink (to payload.md)` keeps passing when M21.39 moves that function onto this module.

Writes are atomic: a temp file created exclusively in the verified parent, the destination and parent re-checked with `lstat` right before `os.replace`. Locks open with `O_NOFOLLOW` where the platform defines it; where `os.O_NOFOLLOW` is absent (Windows), `lstat` the final component, refuse a symlink, then open without the flag.

Decisions:

- **In-repo links are refused too.** Finish already refuses them for `roadmap.md` / `roadmap-context.md` (`irregular_destination`); Publish must refuse them as well (ops-grok FAIL). `refused_generated_files` switches to the rule, so the `link_in` rows in tests/test_writers_refuse_links_out.py for generated files become refusals. This is a behavior change; record it in the CHANGELOG.
- **Upgrade backstop.** `apply_plan` checks every change before its first mutation. A refresher that bypasses the rule can no longer reach outside.
- **CLI boundary.** `SafeWriteError` is an `OSError`, which today's `except ValueError` handlers miss. Every migrated command (init project, refresh-schemas, specyrd init, refresh-stubs, export, digest, upgrade) prints `error: <message>` on stderr and exits 1, no traceback.
- **Managed blocks.** The ignore files `agent_ignores` writes (`.gitignore`, the Cursor ignore files) go on the rule: a link of any kind at that name is refused. The steering files (`AGENTS.md` through `agents_md_block`, `CLAUDE.md` through `agent_guide_block`) keep `resolves_outside`, so an in-repo `CLAUDE.md` -> `AGENTS.md` alias keeps working.
- **Kept on `resolves_outside` (out of scope):** `agents_md_block`, `agent_guide_block`, `upgrade_templates`, and `refresh_profiles._contained`. The reviewers checked those writers and found them OK. Under `upgrade` they run inside the mirror, so the `apply_plan` invariant covers them. `specyrd_skills` writes through `safe_write` under the skills-link rule (acceptance line 1).
- **An explicit absolute `-o`.** `digest -o /abs/path` outside the checkout is the person's own choice, not a planted link; it stays today's plain write. A relative `-o`, or an absolute one inside the checkout, goes through the rule.
- **Race (deferred).** Descriptor-anchored traversal (openat with `O_NOFOLLOW` per component) is M22.21. This leaf narrows the window with the re-check right before replace.

## Approach

- `safe_write.py`:
  - `check(root, path)`, `mkdirs(root, d)`, `write(root, path, data, mode=None)`, `copy(root, src, dst)`, `remove(root, path)`, `prune_empty(root, d)`, `open_lock(root, path)`, and `SafeWriteError(OSError)`.
  - The walk follows the same shape as `finish_bookkeeping_undo.irregular_destination`. M21.39 moves that function onto this module.
- `managed_block.refused_link` returns the module's refusal text: any symlink on the path is refused, whatever `any_link` says. `resolves_outside` stays for the callers listed above. `apply_managed_block` gains a strict mode; `agent_ignores` uses it, and `_write` then goes through `safe_write.write`.
- `init_project._copy_templates`:
  - A dangling destination link counts as present (`lexists`) and is refused, never created through.
  - A symlinked parent is refused before `mkdir`.
- `refresh_schemas`, `specyrd_init._save_manifest`, `export_roadmap_md` (`reexport_roadmap_md` and `main`'s index write), `digest_cli` (default and a relative `-o`; `-` stays stdout), `generated_files.regenerate_generated_files`, `upgrade_generated.regenerate`: all write through `safe_write.write`.
- `do_next_task_register.regenerated_tracked_paths` (pickup) keeps its tracked-only selection: it renders only the generated names git tracks and writes each through `safe_write.write`; an untracked name is still never created.
- `refresh_stubs._write_if_changed`: the `is_link_path` branch keeps today's `specyrd_skills.ensure_link` (intentional skill links); only the file-write branch goes through `safe_write.write`.
- `refresh_stubs._prune`: a recorded orphan under a symlinked directory is refused, not deleted. An orphan that is itself a symlink is removed as an entry. Empty-parent cleanup uses `prune_empty`, which stops at a parent whose `lstat` is a symlink.
- `archive_restore.restore_archive`: before any mutation, preflight every path the restore touches, lexically from the owned root with no `resolve()`: `record.chunk` (the source it later unlinks), each target chunk `_write_back` will write, every planning `stored` and `origin`, and the manifest, ledger and archive planning directory. Any refusal raises before the first write or move, so a record whose second planning move is unsafe moves nothing.
- `upgrade_plan.apply_plan`: one pass over `plan.changes()` before any change. Each entry's `target` (its real path, before `locate`) must pass `check(checkout, target)`; a write that a refresher made into `mirror.outside` fails it. Otherwise it raises naming each path, and nothing is applied, neither to the checkout nor to the dry run's copy. Declined entries are not changes: their refresher already refused and reported them, and they are not applied.
- `upgrade.main` catches `SafeWriteError` beside `ValueError` (real run and `--dry-run`).
