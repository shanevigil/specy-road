## Intent

The first visible panel: who is working on what, with which harness, model and account, and whether anything is failed or stalled. Built against the mock while the backend lane waits on M16.

Out of scope: per-leaf worktree and review detail (M17.4), outline badges (M17.5), the server route (M17.7), any mutating action.

## Approach

- A new component file, lazy-loaded like the other drawers (ArchiveDrawer, WorkersDrawer); logic stays in M17.2's view model so it is unit-tested without a DOM.
- 404 handling keeps the GUI usable against a server without the route (any 0.3.1 pre-release before M17.7).
- Can run in parallel with M16. Depends on: M17.2.
