## Intent

Found while coordinating M10 (2026-11-02). Two Claude Code executors ran `pkill -f "pytest -q"` (and `pkill -f "pytest -q -x"`) to clear what they took for their own stray test runs. The pattern matches every pytest on the machine, so it terminated the coordinator's pre-landing full-suite runs for M9.10 and M10.12 partway through (SIGTERM, no failure). Several sessions share one machine during a grind, so a process kill by name is never safe for an executor.

## Approach

Add one item to the may-not list in `executor_preamble` (`specy_road/bundled_scripts/role_prompt_rca.py`): no pattern-based kills; stop only a process you started, by its pid. Keep it harness-neutral. Add one or two lines to `docs/orchestration-workers.md` next to the foreground-commands note from M10.15 (the file is near its cap). Extend the existing executor prompt test. Verify with that test and file-limits.
