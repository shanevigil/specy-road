## Intent

Give specy-road one tracked list of behaviour changes that make common project instructions wrong, and have validate point at project agent text that still says the old thing. In batch C, project text outside the managed block told agents to pass `--yes` to `mark-implementation-reviewed` (the floor now forbids it on your own work), to always pass `--on-complete merge` (rc3 refuses a mode that differs from the recorded one without `--override-on-complete`, which agents must not pass), that pickup always pushes the claim (`--local` exists), and that finish never deletes the source branch (`--delete-branch` exists). Nothing surfaced any of it. The report never rewrites project text: root `AGENTS.md`, `CLAUDE.md` and the team addendum are developer-owned.

## Approach

- **Catalogue.** New `specy_road/behaviour_changes.py`: a tuple of frozen dataclass entries `{since, command, flags, now, contradicts}` where `contradicts` is an optional compiled regex for project text that states the old behaviour. Seed the four cited cases. A test imports the CLI's registered command list (as `validate_stale_commands.py` does for `unregistered_commands`) and asserts every `command` and flag exists today (flags from each script's argparse: `finish_task_args.py`, `do_next_task_args.py`, `mark_implementation_reviewed.py`).
- **Report.** New `specy_road/agent_text_report.py` with `warn_contradicted_instructions(project_root)`: read root `AGENTS.md`, `CLAUDE.md` and `.specyrd/AGENTS.team.md`; strip the managed block with `managed_block._split()`; for each line that names the entry's command and matches `contradicts`, print `agents: notice — <file>:<line>: says "<excerpt>"; since <since>: <now>`. Required patterns: `--yes` with `mark-implementation-reviewed`; `--on-complete merge|auto` with `finish-this-task`. The pickup-push and delete-branch cases match phrases such as "always pushes" / "does not delete" only on lines that name the command, to avoid prose false positives.
- **Room in validate.** `specy_road/bundled_scripts/validate_roadmap.py` is at 399 of 400 lines. Move `_REQUIREMENT_PIN`, `pinned_version()` and `warn_if_pin_differs()` (about 35 lines) to new `specy_road/version_pin.py`, re-export them from `validate_roadmap` (`tests/test_validate_roadmap.py` calls `vr.pinned_version` / `vr.warn_if_pin_differs`), and add the one call next to `warn_unregistered_commands(root)`. M13.11 then extends `version_pin.py`.
- **Verify.** Fixture with the four cited sentences → four notices with file:line; a clean file → none; the catalogue test; `tests/test_validate_roadmap.py` pin tests unchanged; `specy-road file-limits`.
