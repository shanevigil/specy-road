## Tier

behavioural: nine timestamp sources with four output shapes, and writers with different failure cleanup, move behind two helpers. Passing tests can miss a changed format.

## Done but wrong

- A timestamp changes shape. At pickup, `grind_session_events` gives a `Z`-suffixed string to the second, six helpers give `+00:00` strings to the second, `session_presence` gives a datetime to the second, and `worker_turn_check` gives a datetime with microseconds. Check: one row per replaced site pins the type and string form it had at pickup.
- `roadmap_chunk_atomic` loses its transaction rollback. It tracks its own temp files and restores earlier chunks when a later write fails. Check: a two-chunk write that fails on the second chunk restores the first chunk's bytes and leaves no temp file.

## If this fails

The assumption most likely to break is that `roadmap_chunk_atomic`'s multi-file rollback can sit on `atomic_write_text` unchanged. If it cannot, putting it on the `os.replace(` allowlist changes acceptance line 6, so the maintainer decides.
