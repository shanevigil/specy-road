## Intent

Split from M13.8 by the maintainer (2026-11-04) after seven review rounds: deciding from free prose whether a sentence
instructs a stale behaviour has an unbounded input class. This leaf ships the project-text lint as a deliberately bounded,
best-effort hint on top of M13.8's behaviour-change catalogue: it flags a sentence only when it names a catalogue command
and carries a mandate cue from a fixed list, and it accepts false negatives.

## Approach

- Reuse M13.8's catalogue (`specy_road/behaviour_changes.py`) for commands, flags and the current-behaviour text.
- A prior implementation exists on the M13.8 branch history (commit aba60158, `specy_road/agent_text_report.py`); start
  from it but apply the bounded rules in the acceptance: literal command token + listed mandate cue in the same sentence,
  one stated sentence-splitting rule, no other heuristics.
- validate calls the report with one line; `validate_roadmap.py` is at its line cap, so put the call through
  `bundled_scripts/validate_notices.py` (create it if no earlier leaf has).
- Document the cue list and the false-negative limit in the docstring and the validate docs line.
