## Intent

Found while coordinating M10 (2026-11-01). Seven Claude Code executor turns ended with `exit 0; READY file missing` after the executor started the full pytest suite as a background job and replied "I'll be notified when it finishes". In a headless worker turn the reply ends the process; nothing resumes the session when the background job finishes, so the result is lost and the leaf stalls until the coordinator notices. The executor preamble says to run the verifier and tests but not how, and a long suite pushes agents toward backgrounding it.

## Approach

Extend step 3 of `executor_preamble` in `specy_road/bundled_scripts/role_prompt_rca.py` with one sentence: run the verifier and tests in the foreground, with a long timeout if the harness has one, and do not end the turn while a command you started is still running. Keep it harness-neutral (no tool names). Add the failure mode and the `worker message` recovery to `docs/orchestration-workers.md`. Extend the existing executor prompt test in `tests/test_models_and_prompt.py`; if `tests/test_context_regressions.py` pins the preamble text, update the pinned text. Verify with those two test files and `specy-road file-limits`.
