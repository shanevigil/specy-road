## Intent

Give the frontend lane a typed contract and tested logic before any server work exists, so M17.3-M17.5 are layout only. Builds against a mock because M16.3.1 (which commits tests/fixtures/orchestration_snapshot_v1.json) has not landed; M17.7's contract test later ties the mock to the real fixture.

Out of scope: components, `api.ts`, any server change.

## Approach

- Required fields mirror M16.3.1's acceptance (the v1 list); schema 2 fields are optional so a v1 server still type-checks. If M16.3.1's list changes before it lands, follow the landed fixture.
- Badge precedence and unknown / missing rendering come from M17.1's approved design.
- Clock injected as a parameter (no `Date.now()` inside the view model) so tests are deterministic.
- Can run in parallel with M16 (no Python files touched). Depends on: M17.1.
