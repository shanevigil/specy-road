## Intent

Five small rc4 fixes from the pre-release checks. Each is a few lines, and none changes a command's behaviour except the pickup hint, which must stop dirtying the tree.

1. Workers W3 (sol W2). The module docstring of worker_adapters.py (:22, :27) says Cursor's default `agent -p` passes `--force` and is "the widest". Since M21.15 the default is `--trust --sandbox enabled`, and `--force` needs `cursor_force: true`. It also says a Claude Code reviewer runs `--bare` unconditionally, but a subscription-authenticated reviewer uses explicit settings mode (reviewer_auth.py).
2. Roadmap W3. `persist_merged_nodes` (roadmap_outline_ops.py:17) and `sync_registry_node_ids` (:269) are non-atomic writers that lost their last production callers when rc4 moved outline writes onto `stage_id_rewrite` / `AtomicWritePlan`. A new caller would bring back the pre-rc4 partial writes. A grep on 2026-11-05 found no callers outside the definitions, one docstring mention (roadmap_id_rewrite_staging.py:26), and the helper-only test tests/test_roadmap_outline_registry.py.
3. Finish W2. `print_orchestration_hint` (on_complete_pickup.py:114) creates `.specyrd/cache/` and writes `pickup-orchestration-hint` without `history_cache.ensure_cache_dir`, which writes the cache's own `.gitignore` of `*`. In a checkout whose `.gitignore` lacks `.specyrd/cache/` (one that never ran `init project` or `refresh-stubs`), the marker is untracked. The next pickup or `mark-implementation-reviewed` then refuses the dirty tree.
4. Finish W4. `on_complete`'s description in git-workflow.schema.json:55 and specyrd-finish.md:27 (step 7) say `merge` / `auto` merge locally "and push". With `land: local` nothing is fetched or pushed.
5. CLI W2. `upgrade_templates.missing_work_template_rels` (:124) has no callers and no test.

Out of scope: other dead code (M16.2.1's decided list and the vulture step); finish's landing logic; Cursor/Claude launch behaviour; the toolkit's own `sr/schemas/` copy, which is refreshed by `specy-road refresh-schemas` as sr/ bookkeeping after landing (sr/ is not a touch zone).

Overlaps checked (2026-11-05): M16.2.1 (Not Started) lists `upgrade_templates.missing_work_template_rels` in its D1 delete list. Whichever lands second drops it from its own list (no conflict in code: both delete the same function). M21.16 edits upgrade.py and upgrade_plan.py, not upgrade_templates.py. M22.10 (rc5 finish fixes) touches finish landing modules, not the schema text or the stub.

## Approach

- worker_adapters.py docstring: Cursor's default is `--trust --sandbox enabled`, and `cursor_force: true` opts into `--trust --force` (the widest), linking `docs/orchestration-workers.md`. A Claude Code reviewer runs bare (API key or `apiKeyHelper`) or in explicit settings mode (subscription), linking `docs/orchestration-reviewer-output.md`. Docstring only.
- Delete `persist_merged_nodes` and `sync_registry_node_ids` and any import only they use, and fix the staging docstring's reference. Delete tests/test_roadmap_outline_registry.py (helper-only; planned test change recorded on this node). Registry `node_id` rewrites stay covered by the public move/indent/group tests (tests/test_move_node_cli.py, tests/test_outline_group_cli.py, tests/test_roadmap_crud_edit_add_remove.py); name the one that asserts it in the implementation summary. Before deleting, rerun `grep -rn` on both names over `specy_road/ gui/ tests/ scripts/`.
- `print_orchestration_hint`: call `ensure_cache_dir(marker.parent)` before writing the marker. New git-repo test: a repo whose `.gitignore` does not mention `.specyrd/cache/`, the hint printed once, then `git status --porcelain` is empty and a second call prints nothing.
- Schema description: `merge` and `auto` land per `land` (`push`, the default, merges onto the remote integration branch and pushes; `local` merges into the local integration branch and fetches and pushes nothing). Make the same change to specyrd-finish.md step 7. Text only; enum and properties unchanged.
- Delete `missing_work_template_rels`.
