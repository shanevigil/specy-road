## Intent

Make worker checks see changes in repositories other than the root. In the reported run `worker reconcile` reported only root paths, and the post-run check said clean although the executor had left an untracked `artifacts/` directory in a sibling repository.

## Approach

- **Configured nested repos in the post-run check.** `git_findings()` in `specy_road/worker_turn_check.py` diffs only the root worktree. Reuse `nested_changes()` from `specy_road/nested_repos.py` (as `worker_reconcile.py` already does) so a changed or untracked path in a configured nested repo is a finding.
- **Sibling repos.** For each repository from `sibling_repos()` (M14.1) under the leaf's worktree, collect `git status --porcelain --untracked-files=normal` paths. Both `worker_reconcile.py` and the post-run check report them as a warning: "sibling repository <path> (not configured in nested_repos, so not checked against touch zones): <paths>". The post-run check never reports clean while any are present. Put the shared helper in `sibling_repos.py` (`sibling_changes(worktree)`).
- **Verify.** Tests: untracked directory in a sibling → reconcile warning and post-run finding; configured nested repo untracked file → post-run finding; nothing outside root → unchanged output.

## Tasks / checklist
