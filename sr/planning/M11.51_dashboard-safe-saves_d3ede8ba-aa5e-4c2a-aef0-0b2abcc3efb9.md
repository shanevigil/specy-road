## Intent

Found in rc field use (2026-11-02). In field use saving a planning file from the dashboard silently overwrote newer edits made on disk, and scripts could not tell which read endpoints exist (an unknown one returned the HTML page). Saves should detect concurrent edits and the read API should be documented and safe to use.

## Approach

Add an optimistic content-hash check to the two file PUT routes, a --read-only server flag that rejects mutating routes, and an /api catch-all returning JSON 404. Verify with the touched test files and file-limits.
