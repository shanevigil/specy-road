## Intent

Reviewer runs are read-only and specy-road writes the review record from structured output. Done when:
- The reviewer prompt asks for a final JSON object matching the review-record schema (Claude --json-schema, Codex --output-schema, Antigravity --json-schema; plain final-message JSON elsewhere) and the adapter writes work/reviews/<ID>/REVIEW-<model>.md from it
- A reviewer run that writes any file other than its notes is reported as a review failure
- A malformed or missing structured output is reported as a rerun request, never recorded as a verdict
