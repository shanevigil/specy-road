## Intent

Two adopters rated this High. `Mirror._copy_dir` copies the whole checkout except `.git` and `work/`, ignored files included, and a dry run does it twice. It moved one dry run from 0.3 seconds to about 15 minutes, printed nothing, and put ignored credentials in the temp directory.

## Approach

Build the mirror from what git tracks plus untracked, non-ignored files, adding only what the refreshes read. Keep M21.37's containment rules and its regression tests. Print one line before copying. Do this after the upgrade series so it lands on settled code.

## Tier

behavioural: the plan comes from the mirror, so leaving files out can change what a dry run predicts, and an equal-plans test passes if neither checkout has a file a refresh reads.

## Done but wrong

- An ignored file a refresh touches is mispredicted: on a checkout where a file a refresh writes or checks is gitignored and present, the dry run's plan equals what the real run then does.
- The secret is kept out on one path only: the ignored secret file and directory are absent from the temp directory on the real run and on the dry run, checked by listing the temp directory while it exists, not from the plan output.

## If this fails

Most likely to break: what the refreshes read cannot be listed in advance (`Mirror` already places some paths on demand). Then extend on-demand placement to those paths and report any ignored path it places. The coordinator decides; the maintainer decides if an ignored path has to be copied.
