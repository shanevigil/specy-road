## Intent

rc4 final review (§3.2, 2026-11-06), items deferred to rc5: places where a preview, a rollback or a matcher does not match the real thing.

1. **Brainstorm verify** strips any bracketed citation, so a quote `[44]` matches a page `[43]` (ops-sol W5).
2. **`upgrade --dry-run`** renders the digest in a scratch repo with one synthetic commit. It predicts that a current digest with "Quality by area" will be rewritten (writers-sol W1).
3. **A refused `apply` batch** after archiving an in-repo linked sheet restores a regular file where the symlink was (writers-sol F4).
4. **Check-then-write race.** M21.37 re-checks right before replace, but a parent swapped between that check and the replace is still followed. Writes and archive moves should traverse by directory descriptor (writers-grok WARNING, writers-sol F2).

## Approach

- **Verify brackets.** `brainstorm_verify._norm` drops a bracket only when it is a citation marker on the page side and absent from the quote at that position. A quote that keeps a bracket must match it exactly (`[43]` vs `[44]`, `[a]` vs `[b]` not found). Keep the typographic folds.
- **Dry-run digest.** The preview renders the digest with the live checkout's history as a read-only input: a separate history source passed to rendering, with no writable links into live `.git`. Dry-run and real-run predictions match.
- **Apply rollback.** The `_restore` snapshot in roadmap_crud_dependency_ops records entry type and link text with the bytes. The rollback recreates a symlink as a symlink.
- **Descriptor-anchored writes.** `safe_write` opens each component with `O_NOFOLLOW` (`os.open(dir_fd=...)`) and does `os.replace(..., src_dir_fd, dst_dir_fd)`. Archive moves use the path as spelled under that traversal, not an earlier `resolve()`. Where `dir_fd` is unsupported (Windows), keep M21.37's re-check.
