## Intent

M16 needs numbers to steer by and a floor that test consolidation may not cross. The metrics script makes the slimming analysis reproducible from the checkout instead of a one-off scratchpad, and the rules make the line budget a review criterion.

## Approach

- Port the counting from the analysis tools named in the reports (subsystem classifier, import count, radon/ruff counts) into one script with no new runtime dependency.
- Coverage floor: `coverage` with `patch = subprocess` (or the sitecustomize hook), `fail_under` in pyproject.toml.
- The baseline JSON is regenerated only by M16.33 and by maintainers; M16 leaves report `--check` deltas in READY.
- Depends on: none. Expected net line delta is the last acceptance line; report `scripts/lean_metrics.py --check` deltas in READY once M16.2 has landed.
- Behaviour-preserving: the parity harness (M16.0) and the review-gate decision table (M16.1) stay green; no function rises above its merge-base complexity.
