## Intent

Chores lag leaves: `chore start` needs the branch created by hand, env_setup never runs for a chore worktree, zones cannot be widened after start (and reconcile then flags coordinator-approved files), review-packet, prompt and review record refuse a chore slug ("unknown node id") so `chore close` records a reviewed chore as unreviewed, and `work/chores/` is missing from the managed .gitignore block.

## Approach

- New `specy_road/chore_ops.py` for branch/worktree creation, env_setup (`worktree_env.setup_worktree_env`) and zone widening; `chore_cli.py` (209; M12.3 adds garden chores there, so depend on it) gains `zones` and the `--worktree` creation path.
- `review_target.py` (370): one resolver hook for chore slugs (the chore's base..head) so the review commands accept them; `review_packet.py` (400) changes only a call line.
- `.gitignore` template and `agent_ignores.py`: `work/chores/` in the managed block.
- Depends on M8.3, which changes the review record path.

- [ ] A1 — Start creates branch and worktree, runs env_setup.

- [ ] A3 — Review commands take a slug; close records reviewed.
