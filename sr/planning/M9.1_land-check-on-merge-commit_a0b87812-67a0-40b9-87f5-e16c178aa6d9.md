## Intent

Regressions 1 and 3 (and the clean-merge half of 4) reached the integration branch because nothing ran the project's gate on the tree that actually lands. Land only a merge commit that passes the configured gate. Design: `docs/design-notes/regression-prevention.md`.

## Approach

Read `land_check_cmd` (and the `--land-check-cmd` override) in a new `specy_road/finish_land_check.py`; `git_workflow_config.py` is near the 400-line cap, so keep the resolver out of it. In `finish_land_integration._merge_and_push`, after `merge_feature_deterministically` and before `git push`: record the pre-merge SHA, `git worktree add --detach <tmp> HEAD`, run the command at `<tmp>/<project prefix>`, always remove the worktree, and on failure `git reset --keep <pre-merge>` in the holder tree. On a rejected push, reset the same way and name the re-run command. pr mode is untouched. Verify with the finish and layout tests (`pytest tests/test_project_layouts.py tests/test_prerelease_s2.py` plus the new tests) and `specy-road file-limits`.
