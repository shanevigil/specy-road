## Intent

After M22.60, the current tree is clean, but history still holds the process content, past home paths, private identities and session links. The rewrite and the force-push are operator-only and irreversible, so the operator needs evidence before running them: a rehearsal on a mirror, a passing gate over every ref, and a ready-to-run script. Final pass, before the 0.3.1 tag. Source: the maintainer's scrub plan (private), sections 3 and 4, approved 2026-11-09.

## Approach

Work only on a fresh `git clone --mirror` with the pull-request refs fetched. Never use a working checkout, and never push. Run `git filter-repo` with:

- `--invert-paths` for `sr/`, `docs/design-notes/`, `scripts/census/`, `scripts/review_effort_study.py`, `.cursor/rules/`, and the pre-`sr` roots of the old toolkit roadmap: `planning/`, `roadmap/`, `work/`, `prompts/`, `gui-spike/`, `vision.md` and `project-design-for-claudeandcursor.md`. Add `scripts/lean_metrics.py` only if the tracked tree no longer holds it; otherwise leave it out and say so in the evidence.
- `--replace-text` for home paths, and for account-directory and private names read from M22.54's untracked local list.
- `--mailmap` that maps the university, machine-hostname and localhost identities, and the personal address if the operator says so, to the public author identity. The identity is a placeholder until the operator fills it in.
- `--message-callback` that deletes `Claude-Session:` lines, rewrites `sr/work/…` mentions to `<private>`, and removes private-name mentions. `Co-Authored-By:` tool trailers stay.

Then run M22.54's gate over every ref's tree, every commit message and every author and committer identity in the mirror.

The evidence goes to an untracked folder outside every tracked tree and is never committed:

- the old-to-new SHA map for every branch and tag;
- the pull-request refs that still hold old commits;
- the gate output;
- a ready-to-run operator script with both routes: force-push every rewritten ref, or push to a new repository.

The script refuses to run while the public-identity placeholder is unset. The agent runs none of its push steps.

## Tier

trust boundary: it prepares an irreversible history rewrite of the public repository; the operator acts on its evidence.

## Done but wrong

- The rewrite misses a ref: the SHA map has one row for every branch and tag in the mirror before the rewrite, and the gate output covers each of them.
- File content changed beyond the rules: for the tip of the WIP branch, the rewritten tree equals the original tree minus the inverted paths, apart from the replace-text substitutions, which are listed.
- The script can run unattended: run with the placeholder unset, it exits non-zero before any git command.

## If this fails

Assumption: filter-repo can rewrite the mirror, pull-request refs included, in one run, and the gate can scan every ref in reasonable time. If a ref cannot be rewritten (for example a pull-request ref the mirror cannot update), list it in the evidence and stop; the operator decides between the force-push and new-repository routes.

## Accepted limits

- Pull-request refs on GitHub cannot be force-pushed; only the Support request (M22.59) purges them.
- Forks and existing clones keep old history.
- Removing paths changes every commit since 2026-04 and every tag, including releases published on PyPI; provenance that cites old SHAs breaks.
