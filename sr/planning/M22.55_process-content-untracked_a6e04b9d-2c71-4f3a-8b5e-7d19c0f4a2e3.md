## Intent

Development-process content outside `sr/` is tracked on main and ships links in the wheel: 28 research and triage notes in `docs/design-notes/`, the census scripts, the reviewer-effort study, and the Cursor rules for this repo. The shipped model-profiles README links to `docs/design-notes/` on GitHub. This leaf takes that content out of the tracked tree in the first pass, inside RC5, before the hygiene gate (M22.54) starts enforcing. `sr/` itself moves later, in M22.60. Source: the maintainer's scrub plan (private), sections 1, 3 and 5, approved 2026-11-09.

## Approach

- Remove `docs/design-notes/`, `scripts/census/`, `scripts/review_effort_study.py` and `.cursor/rules/` from the index with `git rm --cached`, and ignore them in `.gitignore` and `.cursorindexingignore`. In the committing worktree the files stay on disk. A merge into another worktree deletes a path that left the index, so the coordinator copies the four paths to the private archive before this commit is merged anywhere else. The leaf deletes nothing from disk and pushes nothing.
- Fix every live citation outside `sr/`. A citation is a link or path to one of the four removed paths in this repository. Out of scope: mentions and fixtures of a consumer `.cursor/rules` directory (adopters keep that feature), ignore entries, CHANGELOG.md's released sections, `tests/parity/`, and `docs/release-runbook.md` and `docs/toolkit-development.md`, which M22.57 edits.
  - the shipped `specy_road/templates/project/model-profiles/` README, profiles and `harness-facts.yaml`: describe the sources in words, with no link to a removed path;
  - the named `docs/` pages and package docstrings and comments (a diff line under `specy_road/` outside templates changes only a citation);
  - the design-notes entries in both `constraints/file-limits.yaml` copies, in the same commit;
  - the `docs/design-notes/` exclude line in `scripts/lean_metrics.py`.
- Tests: `tests/test_review_effort_study.py` imports and runs the retiring script, so it goes in the same commit as the script. In mixed tests only the read of a removed path and the asserts that depend on it go; every other assert stays: the Cursor and Codex argv asserts in `tests/test_review_record_write.py`, the docs and starter-roster asserts in `tests/test_roster_generate.py`, the runbook and AGENTS.md asserts in `tests/test_release_harness.py`. A test docstring that cites a note loses only the citation. Tests that write `.cursor/rules` into a temporary repository test a product feature and stay.

**Checked before planning:** `scripts/lean_metrics.py` is named by open M16 leaves (M16.1.8, M16.1.11 and M16.8.1 in their zones or acceptance, and most M16 sheets for `lean_metrics --check`), so it stays tracked in this pass. `scripts/review_effort_study.py` is named only by M16.1.6 (Complete) and archived M10 work, so it moves.
