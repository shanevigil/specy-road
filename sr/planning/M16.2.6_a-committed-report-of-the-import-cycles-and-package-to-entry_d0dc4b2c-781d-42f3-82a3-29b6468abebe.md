## Intent

The 45- and 25-module import cycles and 105 package-to-bundled_scripts edges grew one lazy import at a time. A gate that only lets them shrink stops new ones while M16.2.7 and M16.2.8 remove the existing ones.

## Approach

- Split from M16.2.5 in revision 1 (Grok 5); shrink-only replaces 'no component over 10 modules', which would force API changes in core orchestration (D1).
- AST scan with a JSON baseline, next to check_clones.py.
- Depends on: M16.2.5. The last acceptance line is an informational line-change estimate, not a gate; report `scripts/lean_metrics.py --check` deltas in READY once M16.1.7 has landed.
- Behaviour-preserving: the parity harness (M16.1.1) and the review-gate decision table (M16.1.2) stay green; no function rises above its merge-base complexity; docstrings and comments that explain intent are kept or improved, never cut to save lines.
