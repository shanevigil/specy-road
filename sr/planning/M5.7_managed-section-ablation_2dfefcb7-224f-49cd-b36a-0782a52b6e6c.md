## Approach

Maintainer decision (2026-11-02): run the reduced study, 1 app x 3 harnesses (Claude Code, Codex, Cursor agent) x 2 runs x managed section on and off, 12 runs in total, locally rather than in the sandbox VMs. Use one small project created with `specy-road init project` (or the dogfood fixture) with a fixed task list, run each cell with the managed AGENTS.md/CLAUDE.md section present and removed, and record turns, tokens, cost (where reported) and the first-round review outcome per run. Write the results and what they justify (trim, keep, or test further) in a design note under docs/design-notes/. Stop and report rather than exceed 12 runs.
