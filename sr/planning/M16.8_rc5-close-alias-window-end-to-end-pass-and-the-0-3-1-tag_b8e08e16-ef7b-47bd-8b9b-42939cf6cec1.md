## Intent

Measure the end state against the baseline, close the alias window (gate), delete aliases, run the end-to-end pass and fix round, bring the release docs in line, and clear the tag gate. It also holds any fix leaves M16.8.4 produces.

## Approach

Leaves run in id order, which is chain order: every leaf's prerequisites have a smaller id, and no edge points to a later group. There are no group-level dependencies; the leaf edges give the order.

Why together: The alias-window close, the end-to-end pass, the release docs and the tag gate come last. M16.8.9 is what M18, M19 and M20 depend on. New fix leaves from M16.8.4 go here (`add-node --parent M16.8`, then `move-node --index` to place them before M16.8.8), and the planner adds them to M16.8.9's dependencies. The three Complete rc4 fixes once filed here moved to M21 as M21.13-M21.15 (2026-11-05); M16.8.9 still depends on them by node_key (alignment review, 2026-11-05, P1).
