## Intent

Every later M16 leaf moves or merges code and must prove it changed no behaviour. Today that proof is spread over about 4,400 test items that pin internals; a small harness at the user-visible surface (command surface, the leaf loop, the generated files) gives one fast, stable answer. It also absorbs the inventory half of held leaf M12.6.

## Approach

- Build the command list from `cli.py`'s tables (and each group's subparsers) so the inventory cannot drift from the CLI.
- Normalise argparse width (`COLUMNS=100`) and program names before comparing transcripts.
- Reuse the dogfood fixture copy and the existing offline PR-mode path; no network, no `gh`.
- Goldens are data files, not tests: one parametrised test per surface.
- Depends on: none. Expected net line delta is the last acceptance line; report `scripts/lean_metrics.py --check` deltas in READY once M16.2 has landed.
- Behaviour-preserving: the parity harness (M16.0) and the review-gate decision table (M16.1) stay green; no function rises above its merge-base complexity.
