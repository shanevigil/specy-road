## Intent

An isolation spike and a live experiment (2026-11-07) showed Claude Code and Cursor run, authenticate and commit inside bwrap, with writes to the common git config, hooks, home and the main checkout refused. Maintainer approved option B: this replaces M22.5 and M22.32 and makes the shared-checkout risk unreachable on Linux, rather than detecting it after the fact.

## Approach

Add `specy_road/worker_sandbox.py` to build the bwrap argv, and prefix `launch.argv` at the single `Popen` in `worker_runner.py`. Follow the bind list in `sr/work/isolation-spike/report.md`, section B. `sr/work/isolation-spike/sandbox.sh` shows the shape, but its full-directory harness binds are too wide; acceptance is authoritative. Bind `worktrees/<name>/commondir` and `gitdir` read-only (probe 3). Use a per-worker outbox for READY. Keep each harness's state writable.

## Tier

trust boundary: changes what a worker launch can reach.

## Done but wrong

- A worker's turn looks sandboxed but runs outside it. Check: the fake-harness turn's probe writes are refused through the public runner, not only in a unit test of the argv.
- Work is lost or unreachable. Check: after a turn, the commit is on the branch, READY is in `work/reviews/<node>`, and a resume finds its session for Claude and Cursor.

## If this fails

Token refresh under the binds is untested. If a harness loses auth mid-run, the affected turn stops; the coordinator decides whether to add a bind or set an explicit opt-out.

## Accepted limits

- macOS and Windows get a warning, not a sandbox.
- Codex's default inner sandbox may refuse git writes; an explicit `channels.cli` setting must grant them. That does not disable the outer sandbox, and no Codex setting is verified yet.
- Nested repositories' common git dirs are not carved out, so a sandboxed commit there fails.
- Reviewer turns are not wrapped.
- Hiding the default ssh and gh files and environment entries is not general secrets isolation.
- Network stays open, because harnesses need their APIs.
- Refs stay writable; M22.45 flags a moved integration ref.
