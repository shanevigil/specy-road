## Intent

A passing test often proves nothing about the change: BSG-VA found 46.0% of agents' positive validation events carried no bug-discriminating information. For projects that opt in, require the tests a leaf adds or changes to fail before the change and pass after it. This checks test-first evidence; it does not instruct agents to work test-first, which TDAD found raised regressions. Design: `docs/design-notes/regression-prevention.md`.

## Approach

New `specy_road/red_green.py`: reuse `specy_road/integrity.py` (M9.5) to find the changed test functions, build two detached temporary worktrees, overlay the head's test files on the base, run `pytest <node ids> --junitxml` in each and classify outcomes. Register `review red-green` in `review_cli.py` (near the cap). The gate hook goes in `integrity_gate.py` beside M9.6's check. Python only. Verify with fixture-repo tests for each outcome class and `specy-road file-limits`.
