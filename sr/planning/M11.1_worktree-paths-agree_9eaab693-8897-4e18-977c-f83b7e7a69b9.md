## Intent

Found in rc2 field use (2026-11-02) with an overnight coordinator running worktree and clone lanes. review-packet wrote PACKET.md to the main checkout while handoff status read READY from the worktree's own work/reviews/, and a reviewer sandboxed to the worktree could not file its verdict because review record writes to the main checkout. Whole review runs were lost before the writable roots were widened.

## Approach

Trace how each command resolves the reviews directory (review_files.reviews_dir and its callers) and make one resolver the only path. Keep the main checkout's work/reviews/ as the location, since executors are already told to write READY there, and print that path in the reviewer prompt as the writable root a sandbox needs. Verify with the touched test files and file-limits.
