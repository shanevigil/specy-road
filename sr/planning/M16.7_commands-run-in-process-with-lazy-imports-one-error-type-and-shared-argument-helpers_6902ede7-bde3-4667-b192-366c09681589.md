## Intent

Every command currently runs in a second interpreter (about 400 ms for `--help`), and code exists only to pass arguments across that boundary. Fifteen unrelated error classes and 226 exit sites hand-roll the same catch-print-exit.

## Approach

- Convert entry points to `main(argv) -> int` one family at a time; the subprocess-based CLI tests catch regressions.
- Keep `specy-road` and `specyrd` console entry points unchanged.
- Error subclasses keep their names; only the base and the handling change.
- Depends on: M16.6. Expected net line delta is the last acceptance line; report `scripts/lean_metrics.py --check` deltas in READY once M16.2 has landed.
- Behaviour-preserving: the parity harness (M16.0) and the review-gate decision table (M16.1) stay green; no function rises above its merge-base complexity.
