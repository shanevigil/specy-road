## Intent

Let a reviewer see sibling-repository changes without the coordinator hand-appending diffs to PACKET.md every round. Today, without `nested_repos`, the packet prints "<path> is named in the packet but not at commit" for every sibling file and includes no diff.

## Approach

- **Room.** `specy_road/bundled_scripts/review_packet.py` is at 400 lines. Move its argument parser (the `p.add_argument(...)` block near line 369) into new `specy_road/bundled_scripts/review_packet_args.py`.
- **`--extra-diff <path>=<base>`** (repeatable). For each, check `<path>` is a repository top inside the project (`is_repo_top`), then render `git -C <path> diff <base>..HEAD`, its changed paths and HEAD sha with the same section format `review_packet_nested.py` uses for configured nested repos (extend that module with a function taking an explicit path and base). Refuse a bad path or base with the next step.
- **One line per sibling.** Where the packet reports a named path missing at the commit, first check whether the path lies inside a sibling repository from M14.1's `sibling_repos()`; group those by repository and print one line each: "in sibling repository <path>, not configured: pass --extra-diff <path>=<base> or configure nested_repos". Other missing paths keep today's line.
- **Verify.** Tests: a sibling repo with two changed files → one grouped line without `--extra-diff`; with it → its diff section and HEAD; bad path refused.

## Tasks / checklist

- [ ] A1 — `--extra-diff` appends the sibling's diff, changed paths and HEAD; bad input refused.
