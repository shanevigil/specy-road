## Done but wrong

- A patch no longer reaches the code: for each test whose patch target changed, making the patched fake raise makes that test fail.

## If this fails

Most likely to break: every patch can move to the module that owns the name. If a test can only reach a part through the old facade, rewrite it through the public operation, naming the covering test in the commit; the coordinator decides.
