## Intent

After M22.74, the tool-call guard still allows `env -vS "git stash"`, `env -iS "git stash"` and `env -S"git stash"`. Its `env -S` check matches only `-S`, `--split-string` and `--split-string=…` as separate tokens, so `-S` clustered with another short option, or glued to its argument, is missed. The overseer read this from the code and the coordinator verified it with `classify` on 2026-11-18. The operator made it an RC blocker ("M22.76 ok").

## Approach

- Parse env's short options as a cluster: an `S` anywhere in a cluster, or `-S` with text attached, is split-string. The rest of the cluster or the attached text is the command line to classify.
- Reuse M22.74's unwrapping. No new classifier; the rewrite is M23.8.
- Add each form as a table row.
- Depends on: M22.74. M16.8.4 depends on this leaf.

## Tier

trust: it changes the guard that refuses destructive commands.
