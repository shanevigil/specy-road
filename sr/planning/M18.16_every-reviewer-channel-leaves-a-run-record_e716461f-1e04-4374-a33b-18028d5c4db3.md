## Intent

A subagent reviewer hit a five-hour usage limit (429) after 22 minutes and about 300k tokens, with notes written but no record filed, and `review list` showed nothing: the coordinator could not tell the review had started. Only `review delegate` and `prompt --channel cli` write a `RUN-<model>.json`; the paste and subagent channels leave no trace.

## Approach

- `reviewer_run_failure.py` (176): `open_reviewer_run(repo_root, t, model, source)` beside `open_reviewer_cli_run`, writing state `started`.
- `role_prompt.py`: in the non-cli branch of `main`, one call when the role is reviewer (M8.3 owns the file now).
- `review start`: new `bundled_scripts/review_cli_start.py` with the parser and command; registered from `review_cli.py` without growing it (400 lines).
- Status: M15.17 creates `review_run_status.py` to mark superseded RUN records; add the `started` / not-filed state there, computed on read from `run_states` and the review records, so `review record` needs no change.
