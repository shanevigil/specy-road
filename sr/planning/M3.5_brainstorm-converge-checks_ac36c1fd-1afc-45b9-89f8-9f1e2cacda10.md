## Intent

A converge pass that misses an idea, an evidence pass that is too wide, or a verdict resting on unverified evidence is reported before promote.

## Approach

Each item is a small check at an existing seam, with no new subcommands:

- **`cmd_recommend` / `--check` (A1):** `_check_converge` walks every idea and reports missing `cluster_id` or `recommendation` without switching mode or writing the converge prompt.
- **`_print_rows` (A2):** critic lines use the same `verdicts` flag as recommendation and `why:` — only when `--show-verdicts` is set (cluster listing is the primary triage view).
- **Evidence selector (A3):** `shortlist` defaults to non-rejected `strong` ideas; explicit ids still win. `cmd_evidence` warns on stderr above `MAX_EVIDENCE_IDEAS` (15) but still emits the prompt.
- **`brainstorm_verify` / fields (A4):** successful quote checks persist `matched`; `VERIFICATION_ALIASES` maps legacy session YAML `retrieved` → `matched` on read and re-serializes as `matched`.
- **`promote` (A5):** `unverified_strong` lists accepted, not-yet-promoted `strong` ideas with no `matched` source; one stderr warning each, naming `verify` or `evidence <ID>`.

Docs: `docs/brainstorming.md` for operator-facing behaviour; `docs/agentic-sandbox-runbook.md` step 6 aligned to `matched` (review round 2). Roadmap touch zones include both doc paths.
