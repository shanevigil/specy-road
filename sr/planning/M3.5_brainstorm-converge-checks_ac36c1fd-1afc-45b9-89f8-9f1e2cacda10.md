## Intent

A converge pass that misses an idea, an evidence pass that is too wide, or a verdict resting on unverified evidence is reported before promote.

## Approach

Each item is a small check at an existing seam: cmd_recommend (the --check flag inspects the session), _print_rows (critics gated), the evidence selector (default and count), brainstorm_verify (state name with a read-side alias), promote (source verification state is already on each idea).

## Tasks / checklist

- [ ] recommend --check
- [ ] critic gating
- [ ] evidence default and warning
- [ ] verify state rename with alias
- [ ] promote warning
- [ ] Tests
