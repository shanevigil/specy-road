## Intent

The rc5 release PR's CI failed on tests that pass on the orchestration host. Two test set-ups depend on the host's environment; this leaf makes them hold in CI's environment too, so the release candidate can be validated and published. No shipped code changes.

1. `gui/pm-gantt/src/orchestrationSnapshot.test.ts` fails on Node 20 with "ReferenceError: navigator is not defined". The test builds its own window, which has a `navigator`, and installs `window`, `document` and others as globals, but not `navigator`; react-dom's client reads the bare global when it is imported. Node 21 and later supply a global `navigator`; Node 20 (CI and the publish workflow) does not.
2. Fifteen tests fail with "No module named 'openai'" where only `.[dev]` is installed, as in `requirements-ci.txt`: `tests/unit/test_brainstorm_chat.py` (6), `tests/gui/test_gui_app_brainstorm.py` (5), `tests/flows/review/test_review_node.py` (4). They use the test fake `use_fake_llm` in `tests/helpers.py`, which replaces `llm_client.make_client`; `llm_client.complete()` then runs `from openai import AzureOpenAI` for a type check. `openai` is in the `[gui]` and `[review]` extras, not `[dev]`.

There is no user-visible defect: a real run goes through `make_client()`, which needs `openai` for every provider and says so.

## Approach

Test-only (maintainer, 2026-11-23: "Recs approved", choosing the test-only route over a change to `specy_road/llm_client.py`, which is a trust path, and over adding `openai` to the `dev` extra).

1. In `gui/pm-gantt/src/orchestrationSnapshot.test.ts`, install the test window's `navigator` as a global together with the other globals the test installs, in a way that works where the built-in global is a getter (Node 21 and later) and where there is none (Node 20).
2. In `tests/helpers.py`, `use_fake_llm` supplies a minimal stand-in `openai` module for the test's duration only when the real package cannot be imported, so the fake client takes the non-Azure branch of `complete()` as it does where the package is installed. Use `monkeypatch` so nothing outlives the test.

Do not change `specy_road/llm_client.py`, `pyproject.toml`, `requirements-ci.txt`, `requirements-ci.in`, any workflow, or anything under `specy_road/pm_gantt_static/`. If the fix seems to need one of them, stop and report.

Verify: `cd gui/pm-gantt && npm ci && NODE_OPTIONS=--no-experimental-global-navigator npm test && npm test`; `pytest -n 4` in the usual environment; and the three test files named above in an environment without `openai` (a Python 3.12 virtual environment built from `requirements-ci.txt`).
