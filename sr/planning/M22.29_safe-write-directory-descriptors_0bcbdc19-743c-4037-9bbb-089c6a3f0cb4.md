## Intent

Source: M22.21 (split 2026-11-06), item 4, moved out with its share of M22.21's line-change estimate. rc4 final review (§3.2, 2026-11-06): **check-then-write race.** M21.37 re-checks right before replace, but a parent swapped between that check and the replace is still followed. Writes and archive moves should traverse by directory descriptor (writers-grok WARNING, writers-sol F2).

Close the window: once the walk has checked a directory, the write happens in that directory, whatever its path points at by then. Which links are refused does not change; that is M21.37's rule. Out of scope: writers that M21.37 leaves on `resolves_outside`, and any concurrency beyond one swap of a destination or an ancestor.

## Approach

- **Walk by descriptor.** `safe_write` opens the owned root once, then each directory below it with `os.open(name, O_RDONLY | O_DIRECTORY | O_NOFOLLOW, dir_fd=parent)`. A link or a non-directory fails the open and is refused with M21.37's message. The parent's descriptor stays open until the write is done.
- **Write through the held parent.** The temp file is created with `O_CREAT | O_EXCL | O_NOFOLLOW` relative to the parent descriptor. The final component is checked with `os.stat(..., dir_fd=parent, follow_symlinks=False)`, then `os.replace(tmp, name, src_dir_fd=parent, dst_dir_fd=parent)`.
- **Detect the swap.** Right before the replace, each held descriptor's `(st_dev, st_ino)` is compared with an `lstat` of its path; a mismatch is refused and the temp file removed. A swap after that comparison can only send the write into the original directory, never outside.
- **Archive moves.** `archive_ops._move_planning_sheets` drops `origin.resolve()`. It reaches the source and destination parents through the same walk and moves with `os.replace(..., src_dir_fd, dst_dir_fd)`, using the path as spelled. How an in-repo linked sheet is moved does not change.
- **No `dir_fd` (Windows).** Where `os.supports_dir_fd` lacks `os.open` or `os.replace`, keep M21.37's `lstat` re-check before replace.
