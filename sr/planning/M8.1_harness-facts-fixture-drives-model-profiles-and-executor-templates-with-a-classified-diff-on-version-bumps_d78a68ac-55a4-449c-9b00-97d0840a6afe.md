## Intent

Harness facts fixture drives model-profiles and executor templates, with a classified diff on version bumps. Done when:
- A tracked harness-facts fixture (one record per harness: version, headless command, session flags, permission example, instruction files and size guidance, skill dirs, hooks, autonomous git actions and switches, model families, quota behaviour, evidence with labels) validates against a schema
- refresh-profiles renders model-profiles/ and the executor command templates from the fixture; hand edits to rendered files are reported as drift
- A version-bump diff of --version, --help and inventories is classified before a refresh is accepted; a new identifier containing plan, memory, task, todo, worktree, branch, commit, push, pr, background, delegate, cloud, schedule, review, resume, fork or autopilot fails the diff until it is assigned a relationship

## Approach

Maintainer decision (2026-11-02): build the fixture now from facts the repository already cites (model-profiles sources, docs/orchestration-models.md, the orchestration research notes and the worker adapters), and mark every fact not backed by a cited source as `unverified`; M8.7 replaces those labels with runtime results and M7.2's research adds the rest. Add a tracked fixture (one record per harness: Claude Code, Codex, Cursor agent, plus any other rostered harness) and a JSON schema for it under the project templates; a small `specy_road/harness_facts.py` loads and validates it. Extend `refresh-profiles` to render the harness sections of model-profiles/ and the executor command templates from the fixture and to report hand edits to rendered regions as drift. Add the version-bump check: store the last accepted `--version` and `--help` output per harness, diff a new capture, and fail on any new identifier matching the listed workflow words until the fixture assigns it a relationship. Keep each module under its line cap. Verify with new fixture, render and diff tests, `refresh-profiles --check` on this repository, and file-limits.
