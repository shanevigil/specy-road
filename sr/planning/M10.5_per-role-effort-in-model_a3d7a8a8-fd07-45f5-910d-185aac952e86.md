## Intent

The seed article calls thinking budget the lowest-hanging fruit for agent latency. specy-road already records each model's effort levels in `access.effort_map` but never asks for one per role. Reviewers and coordinators rarely need the executor's budget. This leaf makes the level a per-role profile field that prompts and adapters pass through, and keeps the shipped defaults conservative until M10.6 measures the effect on verdicts.

## Approach

Extend `access` validation in `specy_road/model_profiles.py` with `effort_by_role`. Add the `{effort}` placeholder to the placeholder set in `specy_road/worker_sessions.py` and substitute it in `role_prompt.run_cli_channel` and the adapters' custom-command path; the default Claude Code and Codex commands in `worker_adapters.py` (342 lines, cap 400) add the flag directly, and the wrapper environment drops `CLAUDE_CODE_EFFORT_LEVEL`. Document in `docs/orchestration-models.md` and the model-profiles README; set the shipped Claude profiles. Verify with `pytest tests/test_models_and_prompt.py tests/test_worker_adapters.py`.

Converge verdict (brainstorm `agentic-performance`): Extends the existing access.effort_map (principle 3); M3.11 already handles effort-suffixed ids. Docs: orchestration-models.md, model-profiles README, the profile schema section.
