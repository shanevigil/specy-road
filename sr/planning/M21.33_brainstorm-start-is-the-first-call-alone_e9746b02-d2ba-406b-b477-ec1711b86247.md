## Intent

CR5 regression on Cursor, 3 of 3 runs (§9 replay 2026-11-05). Before `brainstorm start`, composer-2.5 grepped `roadmap/` for "M2" in the same step as reading the skill (tool call #1, a parallel grep). The `specyrd-brainstorm` skill already says "Run `specy-road brainstorm start` first … (not even in the same step as this skill)". Composer 2.5 read "step" as the turn and issued the skill read and the grep as parallel tool calls. Claude Code and Codex passed.

Decision: change the wording only, with no CLI enforcement in rc4. The skill names the tool call and the parallel case explicitly: after reading the skill, `specy-road brainstorm start` is the agent's next tool call, alone in its tool-call batch, with no parallel read or search. After it returns, the agent reads the prompt file it names and continues. ("No other tool call in that turn" would forbid that prompt-file read.)

Every harness ships a copy rendered from the one template, `specy_road/templates/specyrd/commands/specyrd-brainstorm.md`, at `.agents/skills/specyrd-brainstorm/SKILL.md`. Claude Code also gets `.claude/skills` as a symlink to `.agents/skills` (`specyrd_skills.LINK_DEST`); Codex and Cursor ship only `.agents/skills`. A test reads each rendered copy.

Overlaps checked (2026-11-05):

- No open M21 leaf touches the template or suggested_prompts/brainstorm-roadmap.md.
- M19.19 (after 0.3.1) lists suggested_prompts/brainstorm-roadmap.md. It lands later.

## Approach

- Front-matter `description`. Replace "(not even in the same step as this skill)" with: "After reading this skill, make `specy-road brainstorm start` your next tool call, alone in its tool-call batch, with no parallel read or search (not roadmap-context.md, roadmap/, planning/ or anything else); after it returns, read the prompt file it names and continue." Keep it within the 1024-character skill description limit.
- First body paragraph: the same sentence, followed by the existing "What you read before round 1 anchors every idea in it."
- suggested_prompts/brainstorm-roadmap.md, Phase 1: the same rule. This follows the maintainer hygiene for prompts that mirror skills.
- Test: run `specyrd init --ai claude-code`, `--ai codex` and `--ai cursor` into tmp dirs. In each `.agents/skills/specyrd-brainstorm/SKILL.md`, assert the sentence in both the description and the body, that the old "same step" wording is gone, and that the description is at most 1024 characters. For claude-code, also assert that `.claude/skills/specyrd-brainstorm/SKILL.md` resolves to that file.
