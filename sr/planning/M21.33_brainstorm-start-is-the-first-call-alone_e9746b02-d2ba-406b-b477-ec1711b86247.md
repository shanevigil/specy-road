## Intent

CR5 regression on Cursor, 3 of 3 runs (§9 replay 2026-11-05). Before `brainstorm start`, composer-2.5 grepped `roadmap/` for "M2" in the same step as reading the skill (tool call #1, a parallel grep). The `specyrd-brainstorm` skill already says "Run `specy-road brainstorm start` first … (not even in the same step as this skill)". Composer 2.5 read "step" as the turn and issued the skill read and the grep as parallel tool calls. Claude Code and Codex passed.

Decision: change the wording only, with no CLI enforcement in rc4. The skill names the tool call and the parallel case explicitly: after reading the skill, the agent's first tool call is `specy-road brainstorm start`, and it issues no other tool call in that turn, including in parallel.

Every harness ships a copy rendered from the one template, `specy_road/templates/specyrd/commands/specyrd-brainstorm.md`: `.claude/skills` for Claude Code and `.agents/skills` for Codex and Cursor. A test reads each rendered copy.

Overlaps checked (2026-11-05):

- No open M21 leaf touches the template or suggested_prompts/brainstorm-roadmap.md.
- M19.19 (after 0.3.1) lists suggested_prompts/brainstorm-roadmap.md. It lands later.

## Approach

- Front-matter `description`. Replace "(not even in the same step as this skill)" with: "Your first tool call after reading this skill is `specy-road brainstorm start`; issue no other tool call in that turn, including in parallel (no read or search of roadmap-context.md, roadmap/, planning/ or anything else)." Keep it within the 1024-character skill description limit.
- First body paragraph: the same sentence, followed by the existing "What you read before round 1 anchors every idea in it."
- suggested_prompts/brainstorm-roadmap.md, Phase 1: the same rule. This follows the maintainer hygiene for prompts that mirror skills.
- Test: run `specyrd init --ai claude-code`, `--ai codex` and `--ai cursor` into tmp dirs. In each rendered `specyrd-brainstorm` SKILL.md, assert the sentence in both the description and the body, and assert that the old "same step" wording is gone.
