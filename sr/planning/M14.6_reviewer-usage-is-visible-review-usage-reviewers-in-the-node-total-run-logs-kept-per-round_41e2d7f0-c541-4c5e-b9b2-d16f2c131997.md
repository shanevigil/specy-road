## Intent

Make reviewer cost visible. `worker usage` covers executors only, and `RUN-<model>.log` is overwritten each round, so only the last round's tokens survive; in the reported run one review session used 2.02M input tokens with no way to see it in the node's cost.

## Approach

- **Keep rounds.** In `specy_road/review_delegate.py`, before a run overwrites `RUN-<model>.json` / `.log`, copy the previous pair into `work/reviews/<ID>/history/` (`HISTORY_DIRNAME` in `review_files.py`) as `RUN-<model>-<commit12>-<n>.json|.log`. The current files stay at their paths so `handoff status` and `review list` are unchanged.
- **Usage.** New `specy_road/review_usage.py`: for each RUN record (current and history), parse token/cost usage from its log with the harness adapter's usage parsing that worker events use (`worker_usage_delta.turn_usage` and the adapters' parsed usage), `?` when not reported. `specy-road review usage <ID>` (subparser registered from `review_usage.py` via an `add_parser` function, as `review_delegate` does, so `review_cli.py` gains about two lines) prints per run and a total; `--json`.
- **Node total.** `usage_lines()` in `specy_road/bundled_scripts/worker_cli_render.py` adds a reviewers line and a combined total when review usage exists.
- **Verify.** Tests: two delegated review rounds (fake adapter output) → both logs kept in history, `review usage` lists two runs and the sum, `worker usage` shows executors, reviewers and total.
