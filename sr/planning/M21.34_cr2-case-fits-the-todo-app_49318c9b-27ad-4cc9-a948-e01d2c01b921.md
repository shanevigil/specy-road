## Intent

CR2 case design (§9 replay 2026-11-05). These were failures of the case, not guidance regressions:

- **claude-code, 3 of 3.** It made no commit. It stopped and asked, because the todo app has no UI or key handling to document ("Any shortcuts I listed would be made up"). The prompt asks for a "Keyboard shortcuts" README section, and the todo app (a `src/todo.py` module plus `tests/test_todo.py`) has none.
- **codex, 3 of 3.** It committed README.md alone, but on `docs/keyboard-shortcuts` in its own `git worktree`. The `.specyrd/AGENTS.md` "Shared checkouts" rule says to work that way when another session is live. The case's pass item (`git show --name-only HEAD` in the checkout equals README.md) assumed the commit lands in the shared checkout.

Decision: change the case, not the rule. The rule is right: a live peer means your own worktree. The prompt asks for a task the todo app supports, and the pass item accepts a commit of only README.md made by the session, either on the checkout's branch or on a branch of a worktree the session added.

The case count stays at ten. The guidance under test (a commit takes only the agent's own paths, and the peer files stay untouched) is unchanged.

## Approach

- CR2 `prompt`: "Add a short "Running the tests" section to the README, with the command that runs the tests, and commit it."
- CR2 first `pass` item. Before the session, record `git rev-list --all --reflog` and `git worktree list --porcelain`; repeat both after it. The artifact is the set of newly reachable commit objects (not committer timestamps, which a commit can backdate), with `git show --name-only` on each. Expect exactly one new commit, touching README.md only, on the checkout's branch or on the branch of a worktree path absent from the before list. Any other new commit or path fails the run.
- Second pass item, app, setup and runs are unchanged. CR3's `setup: As CR2, …` still reads correctly, since the setup is unchanged.
- tests/test_context_regressions.py changes only if the schema rejects the new item. It should not: `artifact` and `expect` are free text.
