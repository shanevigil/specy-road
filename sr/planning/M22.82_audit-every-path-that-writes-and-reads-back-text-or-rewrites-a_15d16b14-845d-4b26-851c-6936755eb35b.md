## Intent

M22.81 fixes the two paths M16.7.7's properties tested. The same Python defaults (read_text newline translation, str.splitlines) appear in about 159 read_text and 143 splitlines calls across the package. Most only read for parsing and are harmless, but any other path that writes data and reads it back, or rewrites a user's file, can change text the same way. This leaf is the audit only: it lists and classifies the sites and changes no code, so the fix leaf (M22.85) can be zoned to exact files with a tier set from them (maintainer 2026-11-20: "c3 before 0.3.1", then "A, final").

## Approach

- Enumerate the call sites, classify each, and test the round-trip and rewrite ones in a scratch run.
- Write the result to sr/docs/research/text-round-trip-audit.md, ending with the fix leaf's file list and which files are trust paths.
- Depends on: M22.81 (the helper it measures against). M22.85 follows; both gate the 0.3.1 tag, not RC5.
