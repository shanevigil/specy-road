## Intent

Restores the Claude Code launch and resume denies that the 2026-11-06 split took off feature/rm-steering-file-guard. Where the harness can refuse a write cheaply, it does: a Claude Code executor is told not to edit or write the in-tree steering files its zones do not name, so the change is stopped before detection or the finish refusal have to catch it.

## Approach

- **First commit:** the leaf starts from the integration branch with `git revert` of R32 (the commit under `## Source`). Conflicts are resolved in that commit by keeping everything predecessors already landed (narrowed M22.5, M22.30, M22.14, M22.10, M22.20 and M22.31) and adding only this leaf's class; no file is taken from narrowed M22.5's version where a predecessor has changed it since. Review covers this leaf's own diff from its merge base, which contains `steering_gate.claude_denies`.
- **At launch, where cheap:** Claude Code launch and resume append `--disallowedTools` `Edit(./<rel>)` and `Write(./<rel>)` per exact file (each in-tree steering file present at launch, plus `.claude/settings.json`, `.claude/settings.local.json` and the three roadmap policy files), skipping exact touch-zone paths. No parent glob, so no rule can match an exempt file. New files, shell writes, the common git dir and the main checkout stay detection-only (relative rules resolve inside the worktree only). Custom `channels.cli` commands keep their argv and get detection only.
- **Other harnesses, written down, not duplicated:** docs/orchestration-harness-launch.md states that Cursor already blocks `.cursor/*.json`, `.vscode/**` and `.git/hooks/**` and that Codex `workspace-write` refuses writes outside the workspace but allows in-tree steering files; neither argv changes. docs/orchestration-review.md "What the gate cannot stop" states what this leaf adds and what stays with M20. docs/orchestration-steering-files.md gets its At launch paragraph.
- **Out of scope:** Cursor and Codex argv changes, OS-level isolation, signing, the M20 posture model, and restoring a changed file.
- **Verify:** the tests below, then one full Sol sweep of the merged result.
