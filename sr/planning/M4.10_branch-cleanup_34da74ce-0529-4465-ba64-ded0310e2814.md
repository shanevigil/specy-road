## Intent

Merged feature branches stop accumulating locally and on the remote.

## Approach

A flag on finish for the common case and a separate prune command for the backlog; both delete only branches the integration branch already contains (reuse grind_session_cleanup's merged-into check).

## Tasks / checklist

- [ ] --delete-branch on finish
- [ ] branches prune
- [ ] docs and skill
