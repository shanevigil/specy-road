## Intent

Guard hooks per harness and avoid lists in every model profile. Done when:
- specyrd init ships checked-in hook files that deny git commit, git push and gh pr for reviewer roles and push, gh pr, worktree and cloud commands for executors, for Claude Code and Codex (documented blocking hooks) and Cursor (reported)
- Every model profile lists the harness features to avoid with the exact switch (memory off, no plan mode, no worktree or cloud features) and the launch template applies them

## Approach

- Hooks (A1, A4): add checked-in hook files under specy_road/templates/specyrd/hooks/ per harness and role (reviewer: deny git commit, git push, gh pr; executor: deny push, gh pr, worktree and cloud commands); Claude hooks exit 2 with onFailure: block; Codex hooks only with the documented loading step; Cursor where hooks are reported to block.
- Avoid lists (A2, A5): every model profile names the features to avoid with the exact switch (from the M11.60 fixture refresh), and the launch templates apply them.
- Pre-push (A3): an optional git pre-push hook that refuses pushes from work/.worktrees/, installed by specyrd init on request and documented as a recipe.

Verify with tests that run each shipped hook script against sample tool calls (blocked vs allowed, exit codes), a profile lint that every profile has an avoid list, and a temp-repo push test for the pre-push hook.
