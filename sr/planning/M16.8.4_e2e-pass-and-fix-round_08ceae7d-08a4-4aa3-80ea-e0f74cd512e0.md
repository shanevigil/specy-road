## Intent

0.3.1 is tagged at the end of M16 (maintainer, 2026-11-05), after one final pass that uses the toolkit as an adopter would, and a round of feedback and fixes. M16 moved most of the code; this pass checks the whole product once more before the tag.

## Approach

- Run from a wheel built from the branch head in a clean virtual environment, never from the editable checkout, so packaging gaps show up.
- Record each checklist step's result below (pass, fail, or not run with the reason).
- Findings become intake entries with a disposition. A fix before 0.3.1 is a new M16 leaf that the planner adds and that M16.8.9 depends on; anything else goes to the post-M16 intake. This leaf changes no product code.
- Human-led: worker and reviewer runs need the maintainer's harness logins, and the feedback round is the maintainer's.
- Depends on: M16.8.3. The last acceptance line is an informational line-change estimate, not a gate.
- rc4 fixes from now on go into this leaf's feedback-and-fix intake, not M15 (maintainer, 2026-11-05): each is an intake entry here with a disposition, and a fix before 0.3.1 becomes a new M16 leaf that M16.8.9 depends on.
