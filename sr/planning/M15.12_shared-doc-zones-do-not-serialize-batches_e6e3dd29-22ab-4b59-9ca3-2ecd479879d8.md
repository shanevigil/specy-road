## Intent

Every leaf names `planning/` and `shared/` in its touch zones, so `grind-session --plan` treated all 34 ready leaves in one repo as overlapping and produced 34 single-leaf batches. Shared documentation directories should not serialize work unless two leaves name the same file.

## Approach

- New `specy_road/shared_zones.py`: the configured shared-zone set (default `planning/`, `shared/`), and `effective_overlap(a_zones, b_zones, shared)` that ignores a shared directory zone but keeps file-level matches under it.
- Use it in `session_plan_render.split_on_zone_overlap` / `zone_overlaps` and in `validate_registry_overlap.touch_zone_overlap`. `session_plan.py` is at 398: change only call sites there.
- Config key: choose one home (git-workflow.yaml `grind` section or orchestration policy) and schema-check it; document in `docs/grind-session.md` within its 500-line override (reword).
