## Intent

Workers and orchestration are canonical specy-road (maintainer, D1). They are 12k lines across 65 modules with no boundary, and the 0.3.1 PM GUI work (M17) will show orchestration and worktree state. Defining the interface and state model first lets M16.5.1-M16.5.9 move code behind it one sub-area at a time.

## Approach

- Interface first, then readers switch to it, then (in later leaves) modules move.
- The snapshot is read-only; writes stay where they are until their sub-area moves.
- Field names are part of the interface; version the snapshot with a `schema` integer.
- Revision 1: a fixed state table replaces the 'orphaned' rule, which would have classed every fresh manual claim as abandoned (Sol 5, Grok 1); the field list is a committed fixture so reviews cannot invent fields (Grok 10, Sol 6).
- Revision 4 (plan review, 2026-11-05) (Sol): behaviour is preserved, so M15.26's delivered reporting and slot rules apply to every row, manual claims included; revision 1's 'a manual claim is never abandoned' is withdrawn. The status truth table (simultaneous workers, manual presence, a READY tip, unreadable inputs) is committed in this sheet in the leaf's first commit.
- Decided (maintainer, 2026-11-05, decision 5b): revision 1's manual-claim exemption is withdrawn; a fresh manual claim is reported exactly as M15.26 reports it today. An exemption would be a named behaviour change in its own leaf, not part of this one.
- Status vocabulary, fixed before pickup: claimed (manual, no worker), running, exited_ok, exited_failed, abandoned (M15.26's rule), unknown.
- The 0.3.1 PM GUI work (M17) reads tests/fixtures/orchestration_snapshot_v1.json: its frontend leaves start after the M17.1 design gate against a mock, M17.6 (schema 2) after this leaf and M17.7 (the route) after M16.3.7; it does not import worker_* or gui_app_routes_workers internals.
- Depends on: M16.2.11. The last acceptance line is an informational line-change estimate, not a gate; report `scripts/lean_metrics.py --check` deltas in READY once M16.1.7 has landed.
- Behaviour-preserving: the parity harness (M16.1.1) and the review-gate decision table (M16.1.2) stay green; no function rises above its merge-base complexity; docstrings and comments that explain intent are kept or improved, never cut to save lines.
- Alignment review (2026-11-05): S1 accepted: A4 adds `specy_road/orchestration/**/*.py` to constraints/file-limits.yaml's globs before the first module lands there; zone constraints/file-limits.yaml. Decision table in the M16 phase sheet.
