## Intent

Five or six commands clean up after landed leaves, each with its own merged/live logic and confirmation UX; doctor already shells out to one of them.

## Approach

- Planner returns a list of actions; `--dry-run` prints them; apply reuses it.
- No new flags beyond `--prune` and `--kind`; old flags map onto them.
- Revision 1: a cleanup fixture with every merged/live/dirty case freezes the old selections (Grok 1, Sol 2); the planner may select less but never more than an old command (safety over sameness where the old rules disagree); the live rule reads the M16.3.1 snapshot, so this leaf follows it (Sol 9).
- M12.5's automatic cleanup is not absorbed; it waits on M16.1.3's decision (Sol 10).
- Depends on: M16.3.7, M16.1.5. The last acceptance line is an informational line-change estimate, not a gate; report `scripts/lean_metrics.py --check` deltas in READY once M16.1.7 has landed.
- Behaviour-preserving: the parity harness (M16.1.1) and the review-gate decision table (M16.1.2) stay green; no function rises above its merge-base complexity; docstrings and comments that explain intent are kept or improved, never cut to save lines.

## Tier

behavioural: one planner now chooses what to delete (branches, worktrees, stashes, registry rows); a test of the planned list passes even if apply removes more, or if the old selections were recorded after the switch.

## Done but wrong

- Apply removes more than it planned: after applying on the fixture, every item not in the plan (unmerged branch, live and dirty worktrees, foreign stash, claimed branch) still exists with its content.
- The old selections came from the new code: the recorded action lists are committed before the planner change and match the old commands run on the merge base.

## If this fails

Most likely to break: the old commands disagree on an item, so no single rule reproduces them. The safer selection becomes a decided row in the reconciliation table; the coordinator records it, and the maintainer decides any row that selects more than an old command did.
