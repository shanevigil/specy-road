## Intent

Ship skills once and meter every file each harness injects. Done when:
- specyrd init writes skills to .agents/skills plus .claude/skills only; upgrade --prune removes the .cursor and .codex copies; validate warns when a mirrored copy still exists
- The context meter counts, per harness, every file it injects: Cursor AGENTS.md, CLAUDE.md and .cursor/rules; Copilot AGENTS.md, .claude/CLAUDE.md and .github/copilot-instructions.md; Codex the 32 KiB chain, with a note when a global AGENTS.override.md exists

## Approach

Start by checking what already exists, because part of A1 has shipped: `specy_road/specyrd_skills.py` writes each skill once to `.agents/skills/<name>/SKILL.md` and adds a `.claude/skills` link for Claude Code. Confirm `specyrd init` writes nothing under `.cursor/` or `.codex/` skill paths; make `upgrade --prune` (via refresh-stubs) delete pre-existing `.cursor` and `.codex` skill or command copies that specy-road wrote; and add a non-fatal `validate` warning when such a mirrored copy still exists. `refresh_stubs.py` is at its 400-line cap, so put new prune or detection logic in `specyrd_skills.py` or a small helper. For A2, extend the context meter in `specy_road/agents_md_block.py` (which already measures CLAUDE.md and the Codex AGENTS chain with its 32 KiB truncation) to report, per harness, every file that harness injects: Cursor (AGENTS.md, CLAUDE.md, .cursor/rules), Copilot (AGENTS.md, .claude/CLAUDE.md, .github/copilot-instructions.md) and Codex (the chain, plus a note when a global AGENTS.override.md exists in the user's Codex home). Document the per-harness list in `docs/install-and-usage.md`. Verify with the specyrd init, refresh-stubs, upgrade and agents-md tests, and file-limits.
