## Intent

Keep specy-road's footprint in a project's root `AGENTS.md` small and non-duplicative. In the reports, the 18-line managed block (a pointer plus seven floor bullets that `.specyrd/AGENTS.md` repeats) pushed a project file from 400 to 418 lines; the first upgrade that created `.specyrd/AGENTS.md` did not say that the adopter's own pickup rules now duplicated it (one copy had gone stale); and the Claude Code context line gave per-file figures with no per-harness total, hiding that the floor rules are read twice through `CLAUDE.md` imports.

## Approach

- **Setting.** Read `agents_block` from `.specyrd/manifest.json` (`full` default, `minimal`) in `specy_road/agents_md_block.py`. `minimal` renders a block of at most 3 lines: the "Written by" line and one pointer to `.specyrd/AGENTS.md` and the team/local addenda. Keep the floor bullets in `full` and add one line in `specy_road/templates/specyrd/agents-md-block.md` saying why (agents that read only the root file still get the floor). Thread the setting through `render_agents_lines()` / `apply_agents_md_block()`, so refresh-stubs and upgrade honour it without changes of their own. `claude-md-block.md` gets the same choice only if it repeats bullets; otherwise leave it.
- **Duplicate notice.** Extend `print_migration()` (upgrade already calls it) or add a sibling called from `apply_agents_and_report()`: when `.specyrd/AGENTS.md` is being created, print its `##` headings, then each heading in the project's own `AGENTS.md` text outside the managed block that matches one case-insensitively (whitespace-normalised), with: "compare these with .specyrd/AGENTS.md and drop the copy that is stale".
- **Totals.** In `print_injected_context()`, end the Claude Code line with a total in lines and bytes, counting a file reached twice (imported from `CLAUDE.md` and also loaded directly) once and saying "(<file> imported twice, counted once)". Codex/Cursor/Copilot lines already end in byte totals; add line totals for parity.
- **Docs and prompts.** Document `agents_block` in `docs/install-and-usage.md` (upgrade section) and update `suggested_prompts/bootstrap-agents-md.md` if it describes the block's contents (maintainer hygiene rule).
- **Verify.** Tests under `tests/`: render full and minimal blocks (minimal ≤ 3 lines; validate's context line shrinks accordingly); a project AGENTS.md with a heading matching one in the rules file → notice lines; Claude Code total with a doubly imported file.

## Tasks / checklist

- [ ] A1 — `agents_block: minimal` yields a ≤ 3-line pointer block via refresh-stubs and upgrade; full block keeps bullets plus a one-line reason; context lines reflect the size. Test renders both.
- [ ] A2 — First creation of `.specyrd/AGENTS.md` prints its headings and names matching headings in the project's own AGENTS.md text, with a compare line. Test with a duplicated heading.
- [ ] A3 — Each harness context line ends with a lines/bytes total, double imports counted once and noted.
- [ ] A4 — Out of scope: removing floor bullets from the default, editing project text outside managed blocks, rewriting `.specyrd/AGENTS.md` content.
