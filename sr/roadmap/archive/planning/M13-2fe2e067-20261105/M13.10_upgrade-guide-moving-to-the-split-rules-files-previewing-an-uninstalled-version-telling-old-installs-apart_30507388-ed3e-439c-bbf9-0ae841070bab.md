## Intent

Write the upgrade guidance adopters asked for and could not find: where project text should go now that specy-road's rules live in `.specyrd/AGENTS.md`, how to preview a version you have not installed, and how to tell installs apart when an old one has no `--version`. Also record in the CHANGELOG why file-limits counts differ between versions (it now counts functions in `.tsx` files).

## Approach

- **New doc `docs/upgrading.md`** (`docs/install-and-usage.md` is at 399 of its 400-line cap):
  - "Migrating to the split rules files": a short table of kinds of text → destination. Repo-specific specy-road policy (e.g. "our integration branch is X; reviewers are A and B") → `.specyrd/AGENTS.team.md`. Project rules (build, style, domain) → stay in root `AGENTS.md`. Generic specy-road mechanics now in `.specyrd/AGENTS.md` (pickup, finish, review steps) → delete. One example each; "keep it when unsure"; never edit inside the markers.
  - "Preview a version you have not installed": `python -m venv /tmp/sr-preview`, hash-checked `--no-deps` install per M13.6's recipe, `/tmp/sr-preview/bin/specy-road upgrade --dry-run --repo-root <repo>`, then delete the venv.
  - "Which install is this": `pip show specy-road` (works for 0.1.x, which has no `--version`), `pipx list`, `uv tool list`, with M13.6's `which -a` subsection linked rather than repeated.
- **Link.** Change an existing line of `docs/install-and-usage.md` ("Keeping a consumer repo current") to link `docs/upgrading.md`, so the file stays at or under 400 lines. Wait for M13.6 to land (same file).
- **uv tool receipt.** One note in the install-identification section: a `uv tool install <local wheel>` records the wheel's path in uv's receipt, so `uv tool upgrade` needs that file to still exist; keep the wheel or reinstall from the index.
- **CHANGELOG.** Under the existing `## [Unreleased]` section in `CHANGELOG.md`, add one line under a fitting subsection: file-limits now counts functions in `.tsx` files, so counts under 0.3.1 differ from 0.2.x and CI on an older pin. Do not add a version heading.
- **Verify.** Docs link check if one exists in tests; `specy-road file-limits` (docs are capped).
