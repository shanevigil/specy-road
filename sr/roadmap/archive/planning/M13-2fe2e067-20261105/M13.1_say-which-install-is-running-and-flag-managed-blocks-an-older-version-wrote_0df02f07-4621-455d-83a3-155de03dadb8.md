## Intent

Let an adopter see, before anything is written, which specy-road install is running and whether another one shadows it on PATH; and flag a repo whose managed blocks were written by a different version even when the manifest says otherwise. In the reports, a uv tool install at rc3 sat on PATH while the project's shared env stayed at rc2, a stale `specyrd` launcher made a second install fail, and a managed block read "Written by 0.3.1rc1" under an rc2 tool with no warning, because only `.specyrd/manifest.json`'s `specyrd_version` is compared today.

## Approach

- **Launchers.** Add `launchers_on_path()` to `specy_road/version_skew.py`: walk `PATH` in order, collect each `specy-road` and `specyrd` executable (all matches, like `which -a`), resolve symlinks, and mark whether it lives under the running interpreter's `sys.prefix` (or is the resolved `sys.argv[0]`). Return plain records so `doctor` (here) and `upgrade` (M13.2) print the same thing.
- **Doctor.** `specy_road/bundled_scripts/doctor.py` prints the list in a short "Install" section and warns when the first `specy-road` on PATH is not the running install (name both paths and the fix: `which -a specy-road`, reinstall or reorder PATH). Keep the addition to a call plus rendering; doctor is near the 400-line cap, so put formatting in `version_skew.py`.
- **Block versions.** `recorded_toolkit_version()` already parses `Written by specy-road X` from the root `AGENTS.md` block via `_AGENTS_WRITTEN`. Add a sibling check that reads that line from each managed block (root `AGENTS.md`, `CLAUDE.md`'s block via the same `managed_block._split`) and warns when it differs from the running `__version__`, even if the manifest matches: "AGENTS.md block written by specy-road X, running Y; run `specy-road upgrade`". Emit it from the per-command version check `cli.py` already runs before every known command (`_maybe_warn_running_version_older` → `warn_if_running_version_older()` in `version_skew.py`), so `validate` shows it without this leaf editing `validate_roadmap.py` (M12.3 and M13.4 own that file); the existing older-than-recorded message text is unchanged.
- Keep `warn_if_running_version_older()` and `warn_if_pin_differs()` unchanged.
- **Verify.** Tests under `tests/`: fake PATH with two launcher scripts (one symlink) in temp dirs → order, resolution and shadow warning; a project whose manifest records the running version but whose AGENTS.md block says an older one → warning naming both versions and the file.
