## Intent

Give adopters an RC install recipe that cannot pull a dependency from TestPyPI, cover pipx and uv tool alongside pip, and show how to check which binary is on PATH. Two adopters flagged the current `--index-url https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/` recipe: with both indexes the resolver may take any dependency from TestPyPI, where names can be squatted. One also ran the install twice because a stale `specyrd` launcher blocked it only after `specy-road` was handled.

## Approach

- **Recipe.** In `docs/install-and-usage.md` "Install a release candidate (TestPyPI)", replace the two-index commands with three steps: (1) `pip download --no-deps --index-url https://test.pypi.org/simple/ "specy-road==X.Y.ZrcN" -d <dir>`; (2) compare `sha256sum` of the wheel with the value published in the RC announcement; (3) `pip install --no-deps <wheel>` then `pip install <the wheel's declared dependencies>` from PyPI only (or `pip install <wheel>` with PyPI as the only index, which resolves deps from PyPI). Give the uv equivalent (`uv pip install <wheel>` with default index) and pipx/uv tool forms (`pipx install <wheel>`, `uv tool install <wheel>`). Explain why in two sentences and link `docs/supply-chain-security.md`; remove the `--index-strategy unsafe-best-match` advice.
- **Runbook.** `docs/release-runbook.md`'s RC announcement step publishes the recipe and the wheel's sha256 (from the TestPyPI file listing or the built `dist/`); its own verification commands that use the two-index form move to the same pattern.
- **Install methods.** The Install and "Keeping a consumer repo current" sections show upgrade commands for pip, `pipx upgrade specy-road`, `uv tool upgrade specy-road`. `README.md`'s install block stays short and links there.
- **Which install.** New subsection "Which install is running": `which -a specy-road specyrd`, `specy-road --version`, `readlink -f "$(command -v specyrd)"`, how to remove a stale launcher before reinstalling, and a pointer to `specy-road doctor` (M13.1 adds the launcher list there).
- **Docs test.** Add a test under `tests/` that scans `README.md` and `docs/**/*.md` code fences and fails on any install command combining a `test.pypi.org` `--index-url` with `--extra-index-url`.
- Release notes for rc3 live outside the repo; this leaf changes only tracked docs.
