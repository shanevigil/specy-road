## Intent

Sixty ideas or verdicts are one command and one transaction, duplicates merge instead of being rejected, and gap ideas have a sanctioned origin.

## Approach

Parse the file into the same argparse namespaces the single commands use, validate every record, then write the session once under session_lock. Merged is a new idea status.
