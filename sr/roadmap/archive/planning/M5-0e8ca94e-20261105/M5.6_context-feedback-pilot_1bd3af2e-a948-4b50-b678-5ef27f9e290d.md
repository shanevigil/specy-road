## Intent

The toolkit learns whether agents' reports of missing or wrong context reproduce, before adding a question to every implementation summary.

## Approach

Maintainer decision (2026-11-02): run the pilot locally, not in the sandbox VMs, because the question is about prompt behaviour. Add the three-line structured context-feedback block (missing / wrong / unused, each quoting a line or naming a turn) to the executor prompt behind an opt-in flag, run a small set of scenarios in scratch clones of this repository (for example three closed leaves replayed from their briefs), collect the feedback lines, and check each against the brief and the run to see whether it reproduces. Record the hit rate and the triage rule in a design note under docs/design-notes/. Shipping the block by default stays a separate decision. Keep model spend small: at most six executor runs.
