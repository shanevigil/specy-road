## Intent

Executors can pass a gate by deleting, skipping or loosening tests. Report those edits deterministically from git objects so reviewers and (in M9.6) the gate see them. Python first; the file-level findings work for any language. Design: `docs/design-notes/regression-prevention.md`.

## Approach

New `specy_road/integrity.py` (pure: two commits in, findings out; `git show <ref>:<path>` and `ast`) and a thin `bundled_scripts/integrity_cli.py` registered in `cli.py` / `cli_usage.py`. The merge base and the default ref come from the same resolution `review-packet` uses (`review_target`). Add the packet section in `review_packet.build_packet` after the changed paths. Fixture repos are built in `tmp_path` per test. Verify with the new tests, `pytest tests/test_review_packet.py`, `specy-road file-limits` and the clone check.
