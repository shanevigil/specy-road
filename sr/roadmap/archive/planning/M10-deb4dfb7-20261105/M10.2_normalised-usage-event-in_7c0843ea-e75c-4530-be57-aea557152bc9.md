## Intent

Claude's cost and Codex's usage already land in event detail, in two shapes that nothing reads. One vendor-neutral `usage` event with nullable fields makes cost per role and model comparable across harnesses and is the data the log explorer (M10.12) and the tracked-logs setting (M10.13) build on. Absent must stay distinguishable from zero.

## Approach

Add `usage` to `worker-event.schema.json`. In `specy_road/worker_adapters.py` (cap 400; move parsing helpers to `worker_adapter_parsers.py`) each adapter's `parse` returns the usage fields in `Parsed.detail`; the wrapper (`worker_runner._consume`) appends the `usage` event at turn end, converting Claude's cumulative cost to a delta using the previous usage event. Add `usage` to `worker_cli.py` with rendering in `worker_cli_render.py`. Docs in `docs/orchestration-workers.md`. Verify with `pytest tests/test_worker_adapters.py tests/test_worker_cli.py` using recorded sample lines.

Converge verdict (brainstorm `agentic-performance`): States C2 best; extends what M3.9 adapters already capture (principle 3, 9). Docs: orchestration-workers.md field table; orchestration-models.md prices section.

**Documentation to update in the same change set:** orchestration-workers.md field table; orchestration-models.md prices section.
