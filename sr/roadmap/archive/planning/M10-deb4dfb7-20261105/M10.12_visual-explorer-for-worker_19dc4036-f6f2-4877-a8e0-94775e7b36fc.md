## Intent

PM-requested: a browsable view of what each worker did, the way LangGraph Studio and LangSmith show a run step by step. It is the first human consumer of the phase events (M10.1) and usage events (M10.2); without it the timeline is a file nobody opens. The GUI reads the gitignored worker records from the main worktree and writes nothing.

## Approach

Add `specy_road/gui_app_routes_workers.py` with the two read-only routes, included from `gui_app.py`; reuse `worker_state.list_records` and `events_since` and the timeline arithmetic from `worker_cli_render.py`. In `gui/pm-gantt/src/components/` add `WorkersDrawer.tsx` following `WorkNotesDrawer.tsx`; phase-bar math in a small `workerTimeline.ts` with a vitest. Run `npm ci && npm run lint && npm test && npm run build` per `docs/contributor-guide.md`. Docs in `docs/pm-gui.md`. Verify with `pytest tests/test_gui_app.py tests/test_gui_app_workers.py`.

Converge verdict (brainstorm `agentic-performance`): PM-requested; prerequisite B28 and B10 in this session; the PM GUI already exists so it is an extension, not a new surface (principle 3). Docs: pm-gui.md panel section, orchestration-workers.md pointer to the viewer.
