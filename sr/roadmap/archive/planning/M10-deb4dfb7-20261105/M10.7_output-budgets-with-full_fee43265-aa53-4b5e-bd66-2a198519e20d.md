## Intent

The seed article's point that uncached input drives time to first token lands hardest on the outputs specy-road writes into a model's context: the review packet (a whole diff), the brief, the planner's JSON and validate's diagnostics. Give each a budget with a pointer to the rest, so a reviewer or executor reads a summary first and the full text only when it needs to, and make validate's repeated warnings one line per class. Design: `docs/design-notes/agent-performance-research-triage.md` (recommendation 7).

## Approach

`specy_road/bundled_scripts/review_packet.py` `_diff`: count lines; past `--max-diff-lines` (default 1500) inline whole files until the cap, then list the remaining paths with `+/-` counts from `git diff --numstat`, write the full diff to `DIFF.patch` beside `PACKET.md` and name it; `0` disables both. `generate_brief.py`: compute section sizes once at the end, print the header line and the stderr warning above 65536 bytes. `session_plan_render.py` / `grind_session_args.py`: `--fields` filters `session_plan_to_dict`'s keys, unknown key is an argparse error listing the valid ones. `brief_acceptance.py`: collect the no-acceptance leaves and print one grouped warning plus one hint. Docs: `docs/dev-workflow.md` (packet cap, DIFF.patch, brief size line), `docs/grind-session.md` (`--fields`). Verify with `pytest tests/test_review_packet.py tests/test_generate_brief.py tests/test_session_plan.py tests/test_validate_acceptance_coverage.py`.

Converge verdict (brainstorm `agentic-performance`): Principle 9 smallest change; one cap plus --full per command. Docs: orchestration.md packet section, dev-workflow.md brief section, grind-session.md JSON shape.
