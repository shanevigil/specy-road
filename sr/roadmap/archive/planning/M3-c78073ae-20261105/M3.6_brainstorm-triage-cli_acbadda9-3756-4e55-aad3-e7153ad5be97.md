## Intent

The PM can finish triage without scripts and without a partial write.

## Approach

Each item is a small check at an existing seam, with no new session file:

- **All-or-nothing triage (A1):** `_triage` (accept/reject) and `cmd_park` resolve every id through `set_status` first — missing ids and already-promoted ideas raise before any `[ok]` print or `write_session`. In-memory mutations are discarded on raise.
- **`realize` (A2):** looks up `--node` in the merged graph (`load_roadmap`), then records that node's `node_key` as the idea's `promoted_node_key`. Refuses if the idea is already promoted or the display id is absent.
- **`revise --append-why` (A3):** appends to `verdict_why`; `--why` help names that stored field. `--append-why` wins if both are passed.
- **`list --summary` (A4):** `print_idea_summary` counts every `IDEA_STATUSES` value and every `RECOMMENDATIONS` value plus `-`, from the session.
- **`--reason` (A5):** argparse requires it on reject and park; accept keeps it optional. Each help string says so.

Docs: `docs/brainstorming.md` triage section.
