## Intent

Coordinators wrote sleep loops because `worker sync --wait` returns on any event, including every tool-use output line, which also drowns sync output. `delegate --rework` refused while a completed worker was still listed; a turn that ended with the READY file missing had no cheap fix; and pickup printed the same five-line grind-session hint on every call.

## Approach

- New `worker_cli_sync.py` holds `cmd_sync` and its parser (worker_cli.py is at 393); `--until` filters event types; `worker_state.wait_for_event` gets an optional type filter.
- Collapse in `worker_cli_render._sync_event_lines` with `--verbose` to opt out.
- `role_prompt_rework.rework_check`: completed workers count as ended (coordinate with M14.11, which owns the file now).
- `worker resume --ready-only` with a fixed short prompt; the completion event line names it.
- Pickup hint once per checkout via a marker in `.specyrd/cache/` (`on_complete_pickup.py`).
- Docs: new `docs/orchestration-worker-sync.md` (orchestration-workers.md is at 399).
