## Intent

`finish-this-task` moves a tracked implementation summary from `work/implementation-summary-<ID>.md` to `work/done/implementation-summary-<ID>.md` (`finish_work_artifacts._archive_tracked_summary`). `file_limits_engine.SESSION_ARTIFACT_GLOBS` exempts the first path but not the second. Under the project template's `**/*.md` glob (400 lines), a long summary that passed before finish fails after it lands. An adopter hit this on the integration branch.

## Approach

- Add `"work/done/implementation-summary-*.md"` to `SESSION_ARTIFACT_GLOBS`, next to the existing summary glob, with a one-line comment naming the finish archive.
- Test through the public `file-limits` command on a scaffolded project (template `constraints/file-limits.yaml`) with a 450-line archived summary. A second check in the same test: a 450-line `work/done/notes.md` still fails, which shows the exemption is only for summaries.
- `docs/file-limits.md`: one sentence in the section that lists what is not measured.
