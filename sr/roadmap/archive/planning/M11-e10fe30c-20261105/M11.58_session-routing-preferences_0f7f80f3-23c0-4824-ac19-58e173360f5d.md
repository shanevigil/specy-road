## Intent

The maintainer prefers to set routing preferences in chat as session limits change (which models have budget, when a provider resets, which executor to use for which kind of leaf), rather than as fixed roster config. Today those preferences live only in the coordinator's context or private notes, so a context reset, an account switch or another agent loses them. The decision ledger (M11.34) is the tracked place to keep them.

## Approach

Extend the ledger schema with kind preference and its optional fields; add the skill/prompt sentences; make orchestrate plan print active preferences. Verify with the touched test files and file-limits.
