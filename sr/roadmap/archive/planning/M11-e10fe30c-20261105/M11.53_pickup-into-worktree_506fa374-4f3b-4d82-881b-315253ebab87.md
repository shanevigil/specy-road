## Intent

Found in rc field use (2026-11-02). In field use, picking up from a linked worktree required that worktree to hold the integration branch and to push, which conflicts with a rule that worktrees never push. Claims should be registered and pushed from the main checkout while the leaf's work goes into its own worktree.

## Approach

Add a pickup mode that commits and pushes the registry on the integration branch in the main checkout, then creates the feature branch with git worktree add instead of switching branches. Verify with the touched test files and file-limits.
