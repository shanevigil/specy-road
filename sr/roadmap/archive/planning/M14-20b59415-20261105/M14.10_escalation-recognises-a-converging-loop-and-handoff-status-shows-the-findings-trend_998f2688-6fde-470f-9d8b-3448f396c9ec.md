## Intent

Stop treating a converging loop as a failing one. In the reported run, findings per round fell 13, 2, 2, 1, 0; every acceptance item passed in rounds 2 and 4, and round 4 blocked only on a private test import. Escalation still said "openai reviewers blocked the last 3 rounds" and recommended an RCA. The maintainer's manual "about 4 rounds of new input classes, then defer" rule also counts rounds rather than trend. M12.1's fix-round budget caps spend; this leaf adds the missing signal.

## Approach

- **Trend.** New `specy_road/review_trend.py`: from `review_rounds()` (`specy_road/review_rca.py`), per round the count of blocking findings (all four categories in each blocking record, summed across records) and the failing acceptance ids. `converging(rounds, n)`: over the last `n = escalate_same_acceptance_blocks` rounds the count never rose, fell at least once, and the latest round fails no acceptance id.
- **Escalation.** In `escalation()`, when `converging()` and `policy.escalate_when_converging` is false (the default), skip the `same_family` and `review_rounds` rules; keep `same_acceptance` (it cannot fire while acceptance passes anyway), forced escalation and M12.1's `max_fix_rounds`. `Escalation`/`LoopState` carry a `deferred_converging` flag so status can say so. Note: this changes the default for existing projects; the schema description and the design note say so, and `true` restores today's behaviour.
- **Status.** `handoff status` prints `findings by round: 13, 2, 2, 1, 0; acceptance all pass since round 2` and, when deferred, `converging; escalation deferred`; `--json` adds the list. Put the rendering in `review_trend.py` or in `specy_road/review_status_render.py` (M14.9 may create it) so `review_cli.py` gains one line.
- **Config.** Default in `DEFAULT_POLICY` (`specy_road/orchestration_config.py`) and the schema property.
- **Docs.** `docs/design-notes/review-loop-rca.md`: the convergence rule and why.
- **Verify.** Tests: 13, 2, 2, 1, 0 with passing acceptance → no escalation and the trend line; 3, 3, 3 → escalates; 2, 4, 1 → escalates; a failing acceptance in the latest round → escalates; policy true → today's behaviour.
