# Implementation summary: M16.1.12 — Shipped agent templates carry no maintainer provenance comments

Branch `feature/rm-shipped-templates-carry-no-provenance-comments`, base `3e3e199b`, change commit `1ee97fc5`.

## What changed

- **New maintainer file `specy_road/agent_rule_provenance.md`.** A short header, then one section per template, each opened by a marker line `<!-- template: <name> -->` (`agents-rules.md`, `agents-md-block.md`, `claude-md-block.md`). Each section is the template's text as it was at the base commit, with all 37 provenance comments (27, 8 and 2) still on the line after their rule. It was generated by a script from the base templates, so the bytes match exactly. The marker lines do not match `PROVENANCE`, so neither the scan nor `strip_provenance` treats them as comments. The path is under `specy_road/` but not under `templates/`, `docs/` or `sr/`, it is not a Python module, and it matches none of the `[tool.setuptools.package-data]` globs (there is no `MANIFEST.in`).
- **The three templates** now contain only their former text with every `PROVENANCE` line removed, which is exactly what `strip_provenance` produced from them before.
- **`specy_road/bundled_scripts/chore_garden.py`.** `advisory_rule_findings` scans `_PROVENANCE_FILE` (the new file, found from the package directory as the templates were) instead of the three templates. It still does so only when that file is inside the scanned checkout (`is_relative_to(checkout)`, unchanged), and the match is unchanged (whole-line `PROVENANCE` containing `| enforced: advisory`). Finding paths now name `specy_road/agent_rule_provenance.md`. The `_TEMPLATES` / `_RULE_TEMPLATES` constants are gone, and the module docstring's `advisory-rule` line names the new file.
- **`specy_road/agent_guide_block.py`.** The comment on `PROVENANCE` says where those lines now live. The renderers are untouched: `render_guide_lines`, and `render_rules` / `render_agents_lines` in `agents_md_block.py`, still read the templates.
- **`docs/orchestration-chores.md`.** The `advisory-rule` row names `specy_road/agent_rule_provenance.md` instead of the templates.
- **`CHANGELOG.md`.** One bullet under `[Unreleased]` → `### Changed`: the shipped templates no longer carry maintainer provenance comments.

## Notes for the coordinator

- `strip_provenance` now removes nothing from the shipped templates, because they contain no provenance lines. Its callers are `render_guide_lines` (in the zones) and `agents_md_block._render` (`specy_road/agents_md_block.py`, outside the zones).
