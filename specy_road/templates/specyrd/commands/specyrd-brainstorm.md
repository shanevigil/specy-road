Thin stub — generated by specyrd {{SPECYRD_VERSION}}.

Two modes over one session file. Diverge first, converge second; doing both at
once returns five safe ideas instead of forty.

From the **repository root**:

```bash
cd "$(git rev-parse --show-toplevel)"
```

## 1. Diverge — generate

```bash
specy-road brainstorm start --topic "How do we expand payments?" --under M3
```

This writes `work/brainstorm-<slug>-prompt.md`. **Read that file and follow
it.** It asks you to interrogate the question with the PM before generating,
then to produce volume using named divergence lenses, and to research with your
own tools — web search, plus any brainstorming or ideation slash commands and
skills this IDE gives you. specy-road calls no model and no search API here; you
are the one doing this. Record every idea as you go:

```bash
specy-road brainstorm add-idea --title "…" --rationale "…" --evidence "https://…"
```

Do not rank, cluster, or filter in this pass. Do not run `promote`.

## 2. Converge — assess

```bash
specy-road brainstorm recommend
```

Writes the convergent prompt over the ideas already captured. Cluster
duplicates, flag overlaps with existing nodes, and record a verdict per idea:

```bash
specy-road brainstorm revise B1 --recommendation strong --rationale "…"
```

A recommendation is advice. Accepting and rejecting is the PM's decision.

## 3. Triage and promote (PM)

```bash
specy-road brainstorm list
specy-road brainstorm accept B1 B4 B9
specy-road brainstorm reject B2
specy-road brainstorm promote --dry-run
specy-road brainstorm promote
```

`promote` writes accepted ideas into the graph as real nodes and validates.
Refresh the generated files afterwards:

```bash
specy-road export && specy-road digest
```
