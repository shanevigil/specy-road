```bash
cd "$(git rev-parse --show-toplevel)"
specy-road digest
```

Writes `roadmap-context.md`: the live roadmap, decisions already taken, open
gates, dependencies that were removed, and what has been archived. Read that file
before crawling `planning/` or `work/`.

Commit the result — it is meant to be indexed by your IDE in place of the much
larger corpus it summarises. `--check` fails if it has drifted from the roadmap.

See `docs/agent-search.md`.
