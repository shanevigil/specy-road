```bash
cd "$(git rev-parse --show-toplevel)"
specy-road sync
```

Fast-forwards the integration branch, then runs `validate`, `export` and
`digest`. It **commits nothing**: review the refreshed `roadmap.md` and
`roadmap-context.md` and commit them yourself.

specy-road requires git and a configured remote (origin). See `docs/install-and-usage.md`.
