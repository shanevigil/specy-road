```bash
cd "$(git rev-parse --show-toplevel)"
specy-road abort-task-pickup
```

Precondition: on **`feature/rm-<codename>`** with a **clean** working tree. The registry row is removed with a **new commit on the integration branch** and **`git push`** (same contract as pickup).

Optional: **`--base`**, **`--remote`** (defaults from **`roadmap/git-workflow.yaml`**). If the feature branch has **local commits** not on the remote integration branch, the command **refuses** unless you pass **`--force`** (deletes the branch with **`git branch -D`**; can drop those commits locally). **`--force`** also removes **`work/implementation-summary-<NODE_ID>.md`** if present.
