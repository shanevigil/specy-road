```bash
cd "$(git rev-parse --show-toplevel)"
specy-road search "<query>"
```

Ranked, deduplicated, and scoped so current decisions outrank superseded ones. A raw grep of `planning/` or `work/` returns the same passage many times, because briefs inline their ancestor sheets and shared contracts and pr-bodies re-inline the brief.

Useful variants:

```bash
specy-road search "<query>" --scope archived   # completed work, hidden from IDE indexing
specy-road search M1.2                         # everything about one node
specy-road search "<query>" --kind planning    # planning sheets only
specy-road search "<query>" --json             # machine-readable
```
