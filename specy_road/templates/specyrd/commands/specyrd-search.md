Thin stub — generated by specyrd {{SPECYRD_VERSION}}.

Use this instead of grepping `planning/` or `work/`. Those directories contain a
great deal of duplicated text — a brief inlines its ancestor sheets and every
shared contract, and a pr-body re-inlines the brief — so a raw search there
returns the same passage many times. This is ranked, deduplicated, and scoped so
current decisions outrank superseded ones.

```bash
cd "$(git rev-parse --show-toplevel)"
specy-road search "<query>"
```

Useful variants:

```bash
specy-road search "<query>" --scope archived   # completed work, hidden from IDE indexing
specy-road search M1.2                         # everything about one node
specy-road search "<query>" --kind planning    # planning sheets only
specy-road search "<query>" --json             # machine-readable
```

See `docs/agent-search.md`.
