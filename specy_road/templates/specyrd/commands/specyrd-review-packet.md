Thin stub — writes `work/reviews/<NODE_ID>/PACKET.md`. Generated by specyrd {{SPECYRD_VERSION}}.

Run from the **repository root**. It reads the node's registered feature branch — local, else `origin/<branch>` after `git fetch` — without checking it out, so a coordinator in a shared checkout can run it from any branch:

```bash
cd "$(git rev-parse --show-toplevel)"
specy-road review-packet <NODE_ID>
```

The packet holds the brief (goal and acceptance criteria `A1..An`), the implementation summary, every changed path with touch-zone breaches flagged, the diff since the merge base, and verifier output from the executor's `READY-<agent>.md`.

- Add `--verify-cmd "<cmd>"` (repeatable) to run a verifier now and include its output.
- `--ref <branch>` reviews a different branch or commit.

Hand the packet — and nothing else — to each reviewer in a **fresh session**. A session that wrote the change, or the coordinator's own session, must not review it.

Next: each reviewer runs `/specyrd-review-record`. See `docs/orchestration.md`.
