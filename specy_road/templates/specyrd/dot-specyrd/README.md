# specyrd (optional IDE glue)

This directory is created by **`specyrd init`** from the **specy-road** kit. It records which agent packs were installed; it is **not** a second source of truth for roadmap rules.

- **Canonical workflow** remains the **specy-road** CLI (`specy-road validate`, `brief`, `export`, …) — see the repo [`README.md`](../README.md).
- **Not Spec Kit:** `specyrd` is unrelated to the Spec Kit **`specify`** CLI. **specy-road** uses flat **`planning/*.md`** feature sheets per node — not that tool.

## Adding another IDE later

Run `specyrd init` again with a different `--ai` value (`cursor`, `claude-code`, `codex`). The skills under `.agents/skills/` are one file per command shared by every pack; a second pack adds only its own links (Claude Code reads them through `.claude/skills/`).

## Updating after `pip install -U specy-road`

Run **`specy-road upgrade`** (`--dry-run` first). It runs, in order: `refresh-schemas`, `refresh-profiles`, shipped docs and templates, `refresh-stubs`, `validate`, and `digest --check`. Shipped docs and templates means missing `docs/` files the AGENTS load order names and missing `work/*.template.md` files prompts reference (never overwriting). `refresh-stubs` rewrites only the paths [`manifest.json`](manifest.json) records, adds stubs that shipped since you initialized, and re-applies the managed blocks; with `--prune` it also deletes the stubs this version no longer installs (the pre-0.3.0 `*/commands/specyrd-*.md`). None of them touches your roadmap.

## What this tool owns

[`manifest.json`](manifest.json) lists the paths managed per `--ai` pack, and that list is the whole blast radius of `specyrd init --force` — it overwrites those files and nothing else.

Four files are **yours**, and specy-road only maintains one delimited block inside each: `AGENTS.md`, `.gitignore`, `.cursorindexingignore`, and `CLAUDE.md`. Everything outside `>>> specy-road managed block <<<` is never read and never rewritten, with or without `--force`.

## Agent rules

Beside the project's `roadmap/` (in the nested layout, `sr/.specyrd/`, not this directory):

- **`.specyrd/AGENTS.md`** is specy-road's: the full rules every agent follows. `specy-road upgrade` rewrites it whole; do not edit it. The `AGENTS.md` stub points at it and the `CLAUDE.md` block imports it.
- **`.specyrd/AGENTS.team.md`** is yours and tracked: this repository's specy-road instructions from its developers and PMs. Created when missing, never rewritten, not recorded in `manifest.json`.
- **`.specyrd/AGENTS.local.md`** is yours alone: personal notes, gitignored, never created for you.

Both addenda add to the rules and never relax their floor.

## Generated files

- **`roadmap.md`** — `specy-road export`. Generated **and committed**; `export --check` is the drift gate.
- **`roadmap-context.md`** — `specy-road digest`. Also generated **and committed**, for the same reason: agents read it instead of crawling `planning/` and `work/`, so it must be in the tree they clone. `digest --check` is its drift gate.
- **`.specyrd/cache/`** — derived indexes for `specy-road history` and `specy-road search`. Ignored by a `.gitignore` inside it; disposable, rebuilt on demand.
