# Review lessons

Defect classes that escaped a review once. Every reviewer prompt (`specy-road prompt --role reviewer`) includes the entries below under **Project review lessons**, so each later reviewer checks the diff for them.

Add one with `specy-road decisions add [<NODE_ID>] --kind lesson --summary "<one-line rule>" [--example "<text>"]`; list them with `specy-road decisions list --kind lesson`. One entry per defect class: a top-level bullet with the rule, and optional `Example:` and `From:` sub-bullets.
