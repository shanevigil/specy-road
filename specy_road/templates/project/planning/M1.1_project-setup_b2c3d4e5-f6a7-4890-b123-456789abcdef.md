## Intent

Replace the scaffold's placeholders with this project's own purpose, principles, vision and workflow, and add the first real work to the roadmap. Until that is done, an agent that picks work here has nothing true to read.

## Approach

Edit the files in place; each has a short template to replace. Settle the workflow before adding work, because the integration branch decides where claims and finished work land. Add real work with `specy-road add-node` (it creates the planning sheet), then regenerate the generated files and validate. A human decides the purpose, principles and vision; an agent can draft them from existing docs for the human to approve.

## Tasks / checklist

- [ ] `constitution/purpose.md`: why this project exists and for whom
- [ ] `constitution/principles.md`: how the team decides between competing options
- [ ] `vision.md`: one paragraph on the desired future state
- [ ] `roadmap/git-workflow.yaml`: `integration_branch` and `remote` match the team's trunk; review `on_complete` and `require_implementation_review_before_finish`
- [ ] First real phase or milestone: `specy-road add-node --id M2 --type phase --title "…" --parent-id null` (or `--id M1.2 --type milestone --parent-id M1`), then fill its planning sheet
- [ ] Optional: `specyrd init --ai cursor|claude-code|codex` for IDE skills
- [ ] `specy-road export` and `specy-road digest`, commit both, and `specy-road validate --strict` passes
